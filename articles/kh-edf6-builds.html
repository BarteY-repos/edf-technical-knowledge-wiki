EDF 6 — Builds (community source notes)

EDF 6Community Knowledge HubConversion
Source-backed research / case study · Contributed research; per-claim static, verified, unverified; not independently re-tested

This is a source-attributed research appendix, not a chronology or a replacement for topic reference pages. The observations were contributed in the EDF Knowledge Hub export, snapshot 2026-11-14, revision 54f89cd, compiled by novae (ajane).

Read each statement with its evidence grade and exact build. Verified means a reported game test, static means reverse engineering or source inspection without a reported game test, and unverified is a hypothesis. None of these observations was newly tested for this wiki release.

Facts

Canonical EDF.dll timestamp and SHA-256

Evidence: static · Build: steam-678ccb46 · Fact ID: edf-dll-identity

Canonical EDF.dll: PE TimeDateStamp 0x678CCB46, SHA-256 0d5092393a1b9d8f1b75b0c93d8a8f65615a36a92c46e40349c2b66c733d0916, 35,869,184 bytes, image base 0x180000000, SizeOfImage 0x022CE000.

Basis: PE header and hash of the file the EDF41-to-EDF6 project analyzed; the handoff states the recipient's copy had the same timestamp

Attribution: EDF41-to-EDF6 handoff (shared by Bartey), START_HERE.md, README_FIRST_CANONICAL_EDF6_EDF_DLL.md · 2026-10-14

novae EDF.dll binary matches canonical build

Evidence: static · Build: steam-678ccb46 · Fact ID: user-edf6-dll

novae (ajane)'s EDF.dll is byte-identical to the canonical one: SHA-256 0d5092393a1b9d8f1b75b0c93d8a8f65615a36a92c46e40349c2b66c733d0916, PE TimeDateStamp 0x678CCB46, x64, image base 0x180000000. Every round-4 EDF6 address applies to novae (ajane)'s game. Copy kept in File_Storage/Game_Builds/edf6/steam-678ccb46/.

Basis: sha256sum and PE header of novae (ajane)'s file

Attribution: novae (ajane) · 2026-10-15

Launcher EDF6.exe separated from EDF.dll

Evidence: static · Build: steam-678ccb46 · Fact ID: edf6-module-layout

EDF6 splits a small launcher EDF6.exe (383,488 bytes, SHA-256 87fadc7dbfb6f50d0f1bfea5b3f51af779aeaa9fa03a90c62a695eb39f1e0989) from the game code in EDF.dll; the install also has LaunchGame.exe (1,100,288 bytes) and umbra_sandlot.dll (754,688 bytes). EDF5 has no separate EDF.dll: its code is in the monolithic EDF5.exe.

Basis: file inventory of the analyzed binaries

Attribution: EDF41-to-EDF6 handoff (Bartey), EDF5_EDF6_MISSION_TRANSPILER_R37 section 3.1 · 2026-08-26

Havok 2020 SDK marker and legacy parser

Evidence: static · Build: steam-678ccb46 · Fact ID: edf6-havok-version

EDF.dll embeds the Havok SDK marker hk_2020.1.0-r1 (new-physics hknp* classes) and also carries the legacy Binary Tagfile reader identity Binary Tagfile <=2014.2.

Basis: strings in the exact DLL compared with Havok 2014/2020 SDK sources

Attribution: EDF41-to-EDF6 handoff (Bartey), EDF41_HAVOK_2014_2020_DIRECTLOAD_MAP_ORACLE_AUDIT · 2026-10-01

Exact stock Steam build, PE and archive identity

Scope: three static builds.md source records from the contributor's known-builds.tsv and manifest checker. These fingerprints establish the intended native-file baseline; they do not authenticate an arbitrary installed copy until its bytes are hashed against them.

Steam build: EDF6 app 2291060, build ID 17055427, code depot 2291062 (manifest 3195601213471477029, containing EDF.dll and EDF6.exe) and data depot 2291061 (manifest 1491226774890510293, four CPKs). The source labels this build steam-17055427, tied to appmanifest_2291060.acf. This identity should not be generalized to different release builds or stores.

PE identifiers: EDF6.exe PE timestamp 0x678CCB63, preferred image base 0x140000000, SHA-1 e60031cd9d3d7a76fea1d018bb55479d2b2a55c6; EDF.dll SHA-1 9e259bcf70efbc21bac6d244c93775f5ef4551da. Neither checked PE has a SteamStub .bind section in this source corpus. The contributor calls these plain Steam originals; the hashes and module-layout source, rather than that label alone, are the reproducible match criteria.

Data archive census (byte size, SHA-256):

  • Root.cpk — 8,388,716,520 bytes; 54b42d783afe427ba3248e70b69e5745a2c0eeb0e943a5df4f90f8e4f2f55af0
  • Chunk01.cpk — 461,529,344 bytes; cae8c0158b7f8a56038542116e129f39c93f5f91afdc8f8fc8e40d612565970f
  • Chunk02.cpk — 22,951,431,080 bytes; bf0a3cbf45fbc427a02a39f3fa3c08f9369a3a36ff80d539bf0e1e15f688a4a5
  • DX11.cpk — 5,801,808 bytes; 3c39004cd7f2874879e4cdc85c88dc22869d026823911d6519ed3269bb9b3187

The source's SHA-1 inventory was compared with Steam depot manifests, but this wiki session did not rehash a local 30+ GB EDF6 installation. Full SHA-256 digests here are provided for exact provenance checks and should not be applied to modified or decrypted derivative files.
