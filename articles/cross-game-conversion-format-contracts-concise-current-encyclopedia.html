Evidence level: Historical reconciled source; not automatically current authority. Check newer domain-specific findings.

BVM/AC: semantic transpilation, not syntax conversion. Stack, locals/globals, wrappers, CFG, events, factors, object identity, timing and custom calls all matter. Unknown gameplay calls fail closed.

SGO/DSGO: shared container grammar does not imply universal resource schema. Treat per-resource versions/fields independently. Binary LIST.SGO outranks stale companion JSON for deployment truth.

RAB/MDB/CMPL: rebuild archive conventions and convert embedded payloads by their own ABI. Palm simple-clip material correction is runtime-positive; model/object-role semantics affect rendering/collision.

MAC/MAPB/MAPO/RMPA: structural conversion required. Do not reintroduce universal offsets/template grafting or byte-copy RMPA claims. MAPO object-table stride correction is 0x1C/28 bytes. Mission RMPA remains a separate subsystem from AC transpilation.

FMB/ENKEIRIGHT: structural conversion; simple universal byte deltas and floor-physics claims are obsolete.

MAD/Havok collision: source-only serializer path is independently written. Mandatory gates include wire/layout, conservation, FPI, unique primitive reachability and final-geometry AABBs. Accepted Desert policy is the current compatibility baseline.

NAVMESH HKT: compatibility migration and exact native rebake are different problems. Native EDF6 often retessellates/rebuilds topology; target runtime HKT does not serialize every generator setting. Keep topology, streaming, graph, tree, clearance and identity as separate axes.

NVMD: structural/version migration required. faceData/Section-C identity correction is real but not sufficient for DM019 AI behavior.

MAE/weather: not closed source-only. R2F is a reference-assisted loader diagnostic, not a production synthesis rule.
