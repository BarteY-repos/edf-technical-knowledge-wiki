EDF 4.1 — Hud (community source notes)

EDF 4.1Community Knowledge HubGameplay & AI
Source-backed research / case study · Contributed research; per-claim static, verified, unverified; not independently re-tested

This is a source-attributed research appendix, not a chronology or a replacement for topic reference pages. The observations were contributed in the EDF Knowledge Hub export, snapshot 2026-11-14, revision 54f89cd, compiled by novae (ajane).

Read each statement with its evidence grade and exact build. Verified means a reported game test, static means reverse engineering or source inspection without a reported game test, and unverified is a hypothesis. None of these observations was newly tested for this wiki release.

Armor gauge (HUiHudPowerGuage, FevGrave: HudPlayer_DurabilityGauge)

The gauge's update 3FB1E0 gets armor current and max as floats (through 3F5690), truncates them (cvttss2si at…

Evidence: static · Build: steam-57aab039 · Fact ID: armor-gauge-cap

The gauge's update 3FB1E0 gets armor current and max as floats (through 3F5690), truncates them (cvttss2si at 3FC03A cur, 3FC03E max from [rax+0x168]), caps both at 999999 (mov eax,0xF423F at 3FC046, then two cmp/cmovg on the same eax, so one imm32 at 3FC047 raises both), and formats each with 3FC2D0 (calls after 3FC055 and at 3FC0B2). The same bytes B8 3F 42 0F 00 3B D0 as in EDF5 and EDF6.

Basis: FevGrave's notes; anchor unique (also checked by FevGrave in three copies of the exe)

Addresses (build-specific RVAs unless indicated): 3FB1E0, 3F5690, 3FC03A, 3FC03E, 3FC046, 3FC2D0, 3FC0B2

Attribution: FevGrave (ArmorDisplayCap), novae (ajane)'s EDF 4.1 outside set · 2026-10-16

The text box that may clip long numbers: per FevGrave's PourGaugeUIBox_EDF41.txt (not supplied), the Text_Pow…

Evidence: static · Build: steam-57aab039 · Fact ID: armor-gauge-textbox

The text box that may clip long numbers: per FevGrave's PourGaugeUIBox_EDF41.txt (not supplied), the Text_Pow / TText_Pow box fields at gauge +0x4A8 / +0x4B8 (72.0 / 22.4); the render side is PourGauge.sgo in Root.cpk. The code cap must be raised too, or the display stays at 999999 / 999999 whatever the SGO says.

Basis: FevGrave's notes

Attribution: FevGrave (ArmorDisplayCap), novae (ajane)'s EDF 4.1 outside set · 2026-10-16

EDF41.exe file offsets in .text: file offset = RVA - 0xC00 (image base 140000000, .text at RVA 0x1000, raw 0x…

Evidence: static · Build: steam-57aab039 · Fact ID: text-file-offset

EDF41.exe file offsets in .text: file offset = RVA - 0xC00 (image base 140000000, .text at RVA 0x1000, raw 0x400).

Basis: FevGrave's note (RVA 3FC046 = file 3FB446)

Attribution: FevGrave (ArmorDisplayCap) · 2026-10-16

Vehicle aim line and crosshair colors

Vehicle weapon aim line: cmp dword rbx+0xAB0,0 / jg at 3200DA (above 0 = cooling down)

Evidence: static · Build: steam-57aab039 · Fact ID: aim-line-cooldown

Vehicle weapon aim line: cmp dword [rbx+0xAB0],0 / jg at 3200DA (above 0 = cooling down); the line color is four floats at [rcx+0x104], +0x108, +0x114, +0x118 (ready = the patch's vanilla red: 0, 0, 0.5, 0.5). metoxys's WeaponAimLineContextual keeps the line during cooldown in yellow (white as an option).

Basis: the patch's anchor and code

Addresses (build-specific RVAs unless indicated): 3200DA

Attribution: metoxys (WeaponAimLineContextual), novae (ajane)'s EDF 4.1 outside set · 2026-10-16

metoxys's LaserSight ("an augmented backport" of EDF5's dynamic crosshair color, for about 290 weapons: gray…

Evidence: static · Build: steam-57aab039 · Fact ID: lasersight-hooks

metoxys's LaserSight ("an augmented backport" of EDF5's dynamic crosshair color, for about 290 weapons: gray out of range, white on terrain, red on an enemy in range, blue on an ally) hooks: the XGL system constant writer 5363DA, the crosshair sight state 3F9C90 (original call 3F5410), its clear 3F9DBE, a per-frame update 2B242B (cmp byte [rdi+0x99B],0), the ray range load 2AF276 (constant AB6A10 = 1000.0) and the target hit 2AF580. It casts its own ray with 2AEEF0 and 2AF1D0, takes the weapon range from the weapon's float +0x1A8, and swaps the crosshair pixel shader (0xA70 bytes, DXBC with 7F1738A9 at +4) for its own as the shader is created at 54F91A.

Basis: the patch's 7 anchors (all unique) and code

Addresses (build-specific RVAs unless indicated): 5363DA, 3F9C90, 3F5410, 3F9DBE, 2B242B, 2AF276, AB6A10, 2AF580, 2AEEF0, 2AF1D0, 54F91A

Attribution: metoxys (LaserSight), novae (ajane)'s EDF 4.1 outside set (ExtraPatches) · 2026-10-16

What LaserSight's code reads (offsets as used by the patch): the target's type target+0x180, 1 enemy and 2 ally

Evidence: static · Build: steam-57aab039 · Fact ID: lasersight-fields

What LaserSight's code reads (offsets as used by the patch): the target's type [target+0x180], 1 enemy and 2 ally; the crosshair object's player [+0x4A8] and slot indexes [+0x4B0] / [+0x4B4] into the player's table [+0x12B0] (0xA0-byte entries), the player's weapon array [+0x1290], and a class test [+0x12A0] == 4 before checking a second held weapon (Fencer, per the patch's 2026-05-27 note); eligible weapons by vtable (AA2C78, AA2760, AA2E20, or [w+0x500] and [w+0x690] zero with a sub-object at [w+0x5E0] of vtable AA7F48, AA7FE8 or AA7928).

Basis: decoded from the patch's machine code; meanings from the patch's comments and labels

Addresses (build-specific RVAs unless indicated): AA2C78, AA2760, AA2E20, AA7F48, AA7FE8, AA7928

Attribution: metoxys (LaserSight), novae (ajane)'s EDF 4.1 outside set · 2026-10-16

The game's own laser-sight raycast: the player soldier update tests rdi+0x99B at 2B242B and only then calls 2…

Evidence: static · Build: steam-57aab039 · Fact ID: laser-raycast-vanilla

The game's own laser-sight raycast: the player soldier update tests [rdi+0x99B] at 2B242B and only then calls 2AEEF0 (ray start and direction from [rdi+0xF58] / [rdi+0xF60], else the object's +0x90 / +0x80) and 2AF1D0 (the raycast: range constant AB6A10 = 1000.0, physics world from [CC8528]+0x18 -> +0x88, its virtual +0xF0; each hit goes to 2AF690 at 2AF588). 2AF1D0 and 2AEEF0 have no other callers.

Basis: rizin disassembly; call sites found by scanning .text for E8 rel32

Addresses (build-specific RVAs unless indicated): 2B242B, 2AEEF0, 2AF1D0, AB6A10, CC8528, 2AF690, 2AF588

Attribution: novae (ajane), 2026-10-16 (while reviewing metoxys's LaserSight) · 2026-10-16

LaserSight runs that raycast a second time every frame for every soldier passing 2B242B, whether or not a las…

Evidence: static · Build: steam-57aab039 · Fact ID: lasersight-review

LaserSight runs that raycast a second time every frame for every soldier passing 2B242B, whether or not a laser-sight weapon is held (vanilla never does), into global buffers, with the range taken from the last eligible weapon's +0x1A8; in that private pass the hit handler 2AF690 is skipped. The patch's code fits its allocations exactly (1016, 58 and 3108 bytes), its seven hooks leave no live register clobbered (checked at each return site), and the reconstructed call to 3F5410 passes the original three arguments. Not found: a definite crash bug. The unconditional raycast (states vanilla never raycasts in: no laser weapon, vehicle, dying, mission end) and the unchecked weapon index into [player+0x1290] are the risky parts.

Basis: the patch laid out with its labels and disassembled; game code at every hook read

Addresses (build-specific RVAs unless indicated): 2B242B, 2AF690, 3F5410

Attribution: novae (ajane), 2026-10-16 (novae (ajane) suspects it of occasional crashes) · 2026-10-16

Chat

Chat limits: the character limit mov qword rbp+0xF,0x20 at 4DDD67 (default 32)

Evidence: static · Build: steam-57aab039 · Fact ID: chat-limits

Chat limits: the character limit mov qword [rbp+0xF],0x20 at 4DDD67 (default 32); the text box width mov ebx,400 / cmp ecx,ebx / cmovg ebx,ecx at 413E14 (metoxys's IncreaseChatLimit uses 90 and 1200 with cmovl; "decent values at 1080p").

Basis: the patch's anchors, decoded

Addresses (build-specific RVAs unless indicated): 4DDD67, 413E14

Attribution: metoxys (IncreaseChatLimit), novae (ajane)'s EDF 4.1 outside set · 2026-10-16

Chat performance: the text chat fits every line into one single-line box, measuring its width (UTF-16 wcslen…

Evidence: static · Build: steam-57aab039 · Fact ID: chat-measure-cost

Chat performance: the text chat fits every line into one single-line box, measuring its width (UTF-16 wcslen several times per frame for every string in the history; flag value 4 written at 4BF176, imm32 at 4BF17A); the equipment screen measures the chat history again although it does not show it (call 52BD10 at 4BEEB6, the text measure). metoxys's ImprovePerformance clears the flag and makes the equipment screen measure an empty string. Later games use line breaks instead.

Basis: the patch's anchors and notes

Addresses (build-specific RVAs unless indicated): 4BF176, 52BD10, 4BEEB6

Attribution: metoxys (ImprovePerformance), novae (ajane)'s EDF 4.1 outside set · 2026-10-16

The chat word filter starts with cmp word rbx,0 / jnz at 358C70

Evidence: static · Build: steam-57aab039 · Fact ID: chat-filter

The chat word filter starts with cmp word [rbx],0 / jnz at 358C70; BlueAmulet's RemoveChatCensor (inspired by Souzooka's) jumps over it (EB 6E).

Basis: the patch's anchor, decoded

Addresses (build-specific RVAs unless indicated): 358C70

Attribution: BlueAmulet (RemoveChatCensor), novae (ajane)'s EDF 4.1 outside set · 2026-10-16
