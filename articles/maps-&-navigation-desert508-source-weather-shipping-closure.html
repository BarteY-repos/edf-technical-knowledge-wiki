Desert508 — source-weather shipping closure

UniversalMaps & NavigationMapsEDF 5EDF 6
Source-backed research / case study · Runtime-proven shipping consumer closure

Status: FULL_SOURCE_WEATHER_OFFLINE_PASS__EVENING_AND_SUNSET_RUNTIME_PASS__SHIPPING_CONSUMERS_FULLY_QUALIFIED.

This result is narrower and stronger than a generic weather-converter claim: every retained EDF5 mission that actually uses ig_desert508 is runtime-qualified on its source-authentic preset.

Source-consumer census

An exhaustive scan of the retained EDF5 mission corpus covered 335 MISSION.BVM files. Exactly two reference ig_desert508:

EDF5/MISSION/DLC/DM018/MISSION.BVM -> evening
EDF5/MISSION/DLC/DM020/MISSION.BVM -> sunset

No retained mission uses fine, cloudy, cloudy2 or finecloud on this map.

Runtime evidence

DM018 / DLC1 #4 — EVENING

The source BVM says evening. A later reconciled AC had incorrectly drifted to sunset. The runtime-positive correction changes only the two weather selectors in PreloadMap and Map back to evening.

Mission RMPA remains unchanged. Runtime result: PASS.

DM020 / DLC1 #6 — SUNSET

Source BVM and current mission AC both use sunset. No mission AC/RMPA weather correction is required. Runtime with the source-derived SUNSET weather pair: PASS.

Production resource model

Desert508 is port-owned rather than a native-EDF6 donor composition. Production uses standard target names:

IG_DESERT508_<PRESET>.MAE
IG_DESERT508_<PRESET>.RAB

The reconstructed MAE path uses target ig_desert508.rmpa plus source-derived modern weathers.dsgo; the six EDF5 weather RAB payloads remain byte-exact source files.

Release interpretation

EVENING and SUNSET exhaust the retained shipping-consumer set and both are runtime PASS. The four unused presets are optional completeness work only, not known product defects and not Patch 1.0.2 release blockers.

Do not alter accepted Desert508 MAC/MAD/FMB/NAVMESH or mission RMPA merely to add weather, and do not reintroduce native EDF6 weather donors into this source-derived production path.

Separate the earlier runtime passes from the later resource-name audit

An additional audit of the effective released MAE set showed a structural defect after the two mission-scoped weather runtime positives above. This is a later resource-validation result, not a retraction of the actual mission playtests. The original EDF5 Desert508 weathers.dsgo points its _envMap[0] to ig_base502.rmpa, while the port's archived EVENING and SUNSET MAE records initially stored the embedded weather RMPA block as ig_desert508.rmpa. In the effective five-MAE candidate set, three resolved and these two failed the exact named-record binding check.

The source-preserving correction renames the MAE's internal block to ig_base502.rmpa, leaving the associated RMPA binary payload, source DSGO and all six RAB payloads unchanged. A subsequent five-file binding check reported 5/5 PASS, 0 failures for IG_2000MCITY_E5EVENING, Desert EVENING/SUNSET and the two city E5CLOUDY profiles. This is a structural PASS. No retained later in-game comparison demonstrates that the newly rebuilt MAEs were visually retested after this RMPA-name repair.

The original six Desert508 source profiles are FINE, SUNSET, CLOUDY, CLOUDY2, FINECLOUD and EVENING. Their original source RAB archives have exact SHA-256 identities and are not created by simply renaming an EDF6 environment donor. They carry 4 or 5 DDS entries each, including a local environment texture and a preset-specific sky cubemap; the source RAB record reports SSA version 272 in all six sampled cases. The original EDF5 mission BVM census still establishes only two shipping consumers, so this wider source corpus must not be mistaken for six runtime-qualified missions.

Source completeness and shipping subset are different sets

The examined Desert508 weather bridge reconstructed all six original weather presets in a source-only offline corpus. An actual later incremental patch, however, included only EVENING and SUNSET, the two presets selected by the retained EDF5-derived mission set. The others (FINE, CLOUDY, CLOUDY2, FINECLOUD) were deliberately omitted from that shipped incremental payload, not declared invalid or universally unused by the base game. The package itself was an increment over an existing Patch 1.0.2 installation, not a replacement full-game archive.

A separately compiled source-weather RMPA can pass structural/geometry validation, and a final ZIP can pass all per-file hashes, without proving pixel parity of every unselected profile. The later package audit records runtime acceptance for the two selected Desert508 weather presets and the related per-mission fixes, while the broader six-preset reconstruction remains an offline/source result.
