EDF5 NPC dialogue triggers: joining, wounds, reloading, reinforcements and victory

EDF 5Game technical referencesNPC audio / AI
Technical reference · Source analysis only (unless a source fact is contributor-verified); no new EDF runtime test

EDF5 uses named TalkManager tables. The game object and the current AI state determine whether a line is eligible; it is not simply a fixed sound assigned to an animation. The source identifies the following native talk events:

Trigger Source condition
合流 (joining) A recruit joins a player-led squad
体力低下 (low HP) First crossing below half HP
ダメージ (damage) HP decreased; then approximately 300–599 frames cooldown, excluding certain state values
リロード (reload) A weapon becomes empty and is reloading
増援出現 (reinforcements) Hostile count increased by more than ten, or increased from zero; after at least 900 life frames
気付かれた (spotted) First target after at least 60 frames
勝利 (victory) At least 120 frames without a target
走り出す (start running) A following soldier has moved for around 90 frames under a local-player squad root; 300–899-frame cooldown

The table names are native Japanese strings present in the source. Their English rendering here is an explanation rather than a claim about localized subtitle text. Cooldowns describe the examined AI conditions; actual spoken lines can also depend on table selection and game circumstances.

The native source identifies distinct sound talk tables for Rangers, squad leaders, Fencers, Spriggans, Grim Reapers, civilians and alien types, so a per-actor fixed sound cannot capture the full event machinery.

Source: edf5/soldier-ai.md, edf5-npc-talk-lines, edf5-npc-talk-triggers, edf5-talk-sgo-tables. Native code and Root.cpk table census; no newly recorded dialogue session.
