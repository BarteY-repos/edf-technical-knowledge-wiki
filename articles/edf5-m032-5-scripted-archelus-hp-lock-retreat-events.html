EDF5 M032_5 Monster Elimination Plan: scripted Archelus arrival, HP protection and retreat

EDF 5Game technical referencesMissions / case studies
Technical reference · EDF5 source static analysis; no new runtime qualification

The examined original mission M032_5 (listed as offline mission 37 / online mission 36, Monster Elimination Plan) is the only source script in this surveyed set that spawns e504_monstera_m034_3, the scripted Archelus variant. Its SGO has game_object_level_adjust = 3. This is a mission-level cinematic/progression actor, not simply a boss with ordinary kill-to-clear logic.

  1. Main creates Erginus using 2000 CreateEnemy at spawn point エルギヌス with source HP scale 0.9.
  2. Handler Func_3 fades the BGM, plays radio line AE005_034_E, and creates the variant Archelus at spawn point 新型 (new type).
  3. The script uses 3020 SetNoDamageWhenHPRemain with 10 and 3021 no-damage mode; it assigns advance route 新型進行ルート using 3101.
  4. Later handlers disable invulnerability with a 30 minimum-HP protection and register an 9200 condition at 85% durability.
  5. The ending switches no-damage protection back on and sends Archelus along 新型撤退ルート (new-type retreat route); after AE141_084_E the script clears the mission with MissionClear.

Therefore the scripted Archelus can take damage yet is not intended to be killed in this sequence. Seeing it retreat without dying is supported by the authored source control flow, not evidence of a broken damage model.

Boundary: the original contributor did not completely trace which earlier registrations arm the last two event blocks. This is a source script reconstruction, not a new full in-game observation of every radio cue, branch and animation. Do not infer a universal 3020 threshold ABI for every EDF edition from this one mission.

Evidence: m032-5-scripted-archelus, original disassembly lines and contributor source notes from edf5/mission-vm.md.
