EDF6 Havok joint constraints: child/parent frames, pivots, angular limits and motors

EDF 6Game technical referencesPhysics / joints
Technical reference · Source analysis only (unless a source fact is contributor-verified); no new EDF runtime test

EDF6 SHKT ragdoll joint definitions contain a child/parent relationship, local frames and limit parameters. The analyzed native constraints assign bodyA to the child and bodyB to the parent; local joint-frame transforms reconstruct nearly coincident pivots in model space. Across the surveyed constraint bodies the measured pivot mismatch was at most about 0.8 mm.

The source's class census includes hkpRagdollConstraintData, hkpLimitedHingeConstraintData, hkpPrismaticConstraintData, hkpHingeConstraintData and hkpWheelConstraintData inside the modern scene graph. Motor enablement was absent for the surveyed ragdoll and limited-hinge pattern. The nominal target rotation records refer to the transformB frame rather than a second arbitrary world-space pose.

Angular limits are stored with redundant calculated values including inverse cosine and tangent terms, with special sentinels near singular angles, around ±π, for a cone without a lower bound and near π/2. The source derived these rules from thousands of native constraints and reproduced the numeric values using the appropriate single/double-precision order. One should not overwrite only a displayed angular limit and assume the dependent serialized values remain consistent.

This is a format-level mathematical observation. It does not demonstrate that editing a joint makes a character's ragdoll behave plausibly in the game; mass, local transforms, body assignment, collision layers and constraint logic all matter.
