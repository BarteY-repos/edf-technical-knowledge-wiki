EDF6 native Engine RE: 336 symbols and exact RVAs

EDF 6Engine RE & Networking
Technical reference · Exact build static evidence; not a gameplay runtime qualification

This is a build-specific technical index of the native EDF6 executable, not a catalog of stable public API calls. Entries are the consolidated R17 semantic-symbol records. The source archive SHA-256 is 93419d55b395c9452e1b23fbccdb37baba3cdb9c4c63f71bac5e31e809e86784 and the inspected game EDF.dll SHA-256 is 0d5092393a1b9d8f1b75b0c93d8a8f65615a36a92c46e40349c2b66c733d0916.

Meaning of an address: the RVA is relative to the game's analyzed PE image base 0x180000000, not a byte offset in an archive or a portable address in other EDF builds. VA is the associated virtual address for that image. kind=site labels a particular instruction or probe location, not necessarily a callable function entry. kind=global or kind=thunk must likewise not be treated as an ordinary function. The semantic names are researcher labels, not exported symbols or ABI guarantees.

The source's confidence label is preserved unchanged: PROVEN means an evidence-backed static binary claim, not a newly tested game feature; HIGH/MEDIUM are weaker. All 336 records are marked CURRENT by this source database, not globally verified against every EDF6 release.

Useful companion references: 145 struct offsets; 188 non-promoted site/structure claims; RUDP and reconnect; native Engine RE overview.

The full names, summaries, domains, confidence and source references are also available as a downloadable CSV in reference/EDF6_R17_NATIVE_SYMBOLS_336.csv. Static. Static label correction. 86B370 is virtual slot1 of vtable 17FF590, the std::function wrapper for a lambda constructed by HUiChat and taking HUiChatBase::ResultBase.
