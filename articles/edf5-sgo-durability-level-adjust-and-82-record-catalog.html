EDF5 object SGO durability: 82 grouped records, level adjustments and limits

EDF 5Game technical referencesEnemy health / reference data
Technical reference · Source analysis only (unless a source fact is contributor-verified); no new EDF runtime test

EDF5 object SGOs declare xgs_scene_object_class and, for relevant objects, game_object_durability. Some enemies also contain game_object_level_adjust. The Japanese bestiary's baseline tables agree with the product in the 45-value comparison described in the source analysis.

Variant Raw durability Level adjustment Adjusted baseline
Red Hornet 90 1.5 135
Blue Drone 75 1.5 112.5
Short Deroy 825 0.7 577.5
Red/Demon Hornet Queen 3000 1.5 4500
Gold Ant Queen 2800 3.5 9800

These source-level baselines are not a complete runtime HP calculator. Difficulty, online scaling, mission setup, independent destructible subparts and script changes can alter active enemy endurance.

Downloadable full grouped source inventory

data/EDF5_NATIVE_SGO_DURABILITY_82_GROUPS_R134.csv retains 82 grouped source facts across enemy objects, NPCs, vehicles and mission objects. Each row records the native C++ class, raw durability (or its absence), variant labels, source grade, exact fact ID and build. Totals: 37 enemy groups, 24 vehicle groups, 4 NPC/civilian groups and 17 object/spawner groups. Multiple SGOs with the same class/base durability are grouped to match the source census rather than inventing unique classes.

The original inventory labels are retained for provenance. They are not authoritative official English names: the detailed subtype articles correct examples such as the Deroy _m suffix and “AI-controlled” parked vehicles. A generic inventory “used in official missions” can include EDF4.1-source missions retained in EDF5's archive, so it does not prove the enemy spawns in the EDF5 campaign; Erginus King is a counterexample.
