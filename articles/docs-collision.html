Overview

Collision describes the physical space, not automatically the path network AI uses. The studied games include MAD/Havok-derived map structures and SHKT-linked object physics. The exact serializer is generation- and profile-dependent.

Known limits

The triangleIsInterior bits are meaningful in native Havok geometry, but a universal source-only algorithm reproducing native EDF6 bitfields has not been verified. Likewise collision filters can differ for direct bullets and explosion broadphase queries: do not infer that a solid object is necessarily damageable by every attack type.

How bullets meet bodies

A projectile's stopping ray, damage sweep, explosion query and gameplay damage handler are separate stages. See EDF6 native bullet collision filters and 32-layer matrix and EDF5/EDF6 world and motion-property differences. The downloadable matrix is a source-attributed reference for the ordinary zero-system-group policy, not a universal claim about every possible physics filter.
