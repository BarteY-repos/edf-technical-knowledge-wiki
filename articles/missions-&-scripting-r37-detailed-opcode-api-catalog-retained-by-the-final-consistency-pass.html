3450 neighboring-field distinctions

Do not collapse the three nearby radius operations:

  • 3450: EDF5 object +0x2E0 → EDF6 object +0x470; source semantic effect binary-confirmed, AngelScript exposure unresolved, but intentionally omitted in the tested playable DM006_2 compatibility branch as an accepted fidelity deviation (not a current wiki blocker).
  • 3024 SetEncountReportRadius: separate field, EDF5 object +0x2E4.
  • 3150 SetAiFormationRadius: EDF5 object +0x3C4 → EDF6 object +0x56C.

EDF5 initialization context associates +0x2E0/+0x2E4 with the game_object_encount parameter family. This supports the search/encounter-radius interpretation of 3450 but does not prove an exposed target API name.

R37 preservation rules attached to this catalog

  • never inject SetFullLightWeightMode() or ragdoll settings unconditionally;
  • BOM presence/absence is not runtime proof;
  • preserve source timing; no blanket ×1.5 conversion;
  • preserve AI routes and .IsValidity() semantics where required;
  • direct vs compound target API emissions must retain provenance so identical AngelScript method names do not erase distinct EDF5 source semantics.
