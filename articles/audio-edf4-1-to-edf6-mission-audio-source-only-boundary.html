EDF 4.1 → EDF 6 mission audio: source-only boundary

ConversionAudioEDF 4.1EDF 6
Source-backed research / case study · Offline

Evidence level: Offline source-closure PASS. The source package intentionally contains no game audio payloads; actual build from user-owned game data and EDF6 runtime playback remain separate gates.

Scope

The qualified EDF4.1 MissionBundle audio checkpoint defines four atomic output groups and ten output files:

Group Output role
weapon SOUND/PC/EDF41_WEAPON_SE.ACB shared EDF4.1 SE bank
voice.JA EDF41_VOICE.JA.AWB + _LIST.AWE
voice.EN EDF41_VOICE.EN.AWB + _LIST.AWE
table five EDF6 voice tables: CN / EN / JA / KR / SC

Known exception: The group name weapon is historical. Retaining EDF41_WEAPON_SE.ACB for mission/object sound fidelity does not add EDF4.1 player weapons, models or playable-class data to the MissionBundle scope.

Voice-table behavior

Observed native behavior: Native EDF6 rows are preserved. Missing EDF4.1 cue keys gain caption rows rather than replacing the target table wholesale.

The suffix normalizer removes exactly one terminal _E or _S, matching the qualified lookup behavior. Embedded _E/_S text is preserved.

MusenBegin and MusenEnd use the native no-subtitle marker.

Implementation rule: Extend target voice tables minimally; do not regenerate or reorder native EDF6 rows from a source-only approximation.

Build and memory boundary

The runner processes one atomic group at a time so the large JA/EN voice-bank pair does not need to remain resident simultaneously. It verifies source presence/integrity, validates the exact output set, records SHA-256 and fails closed on the first failed group.

A user-owned EDF4.1 installation or the accepted user-supplied All Forces source root may provide source inputs. EDF6 target inputs are likewise user-owned.

Redistribution boundary

Implementation rule: Distributable tooling contains conversion source only, not original ACB/AWB/AWE/voice-table payloads.

The audited All Forces archive used for project research has no root license file. Its availability for private project research is not a public redistribution license.

Runtime boundary

Unresolved: The R5 checkpoint proves source/import/suffix contracts only. Actual audio conversion using the game payloads, EDF6 playback, subtitle timing, multiplayer synchronization and later object-specific cases such as DragonBig401 remain runtime work.

Evidence and source references

Technical claims retain their source/evidence scope. Some internal inputs are not included in the public package.
