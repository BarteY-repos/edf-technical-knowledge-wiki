Native structural profile reference

This reference lists observed native MDB structural profiles. Counts and field lists refer to the stated model corpora, not an exhaustive catalog of all EDF6 assets.

Parameter triples are shown as name — type / size. In the audited data, common scalar/vector encodings are 0/1 (float-like scalar), 1/2 (float2-like), 2/3 (float3-like), 2/4 or 3/4 for four-component legacy/color cases, and selected 4/1 fields are raw-u32 integer/boolean-like scalars. Do not infer universal type semantics beyond observed fields without more corpus evidence.

Interpreting these records

  • Every profile represents an observed serialized instance family, including the order of material fields and sampler slots, not just reflected shader inputs.
  • Unknown shaders and material variations are not ruled out by absence from this bounded corpus.
  • Structural identity alone does not prove byte-for-byte runtime acceptance or pixel parity; specialized profiles still require family-specific game-render validation.
