Observations

Startup logos: 34D320 is the function metoxys calls isDisplayLogo

Evidence: static · Build: steam-57aab039 · Fact ID: startup-logos

Startup logos: 34D320 is the function metoxys calls isDisplayLogo; making it return 1 (mov al,1; ret) skips every logo to the title screen.

Basis: the patch's anchor

Addresses (build-specific RVAs unless indicated): 34D320

Attribution: metoxys (NoSplashscreens), novae (ajane)'s EDF 4.1 outside set · 2026-10-16

Online AFK disconnect branch

Evidence: static · Build: steam-57aab039 · Fact ID: afk-disconnect

The online AFK timeout ("You have been disconnected from the session.") is taken by the jnz at 377F91 (75 57, then lea rcx,[rsi+0x2B8] / call 351360); metoxys's NoOnlineAFKDisconnect makes it a jmp.

Basis: the patch's anchor, decoded

Addresses (build-specific RVAs unless indicated): 377F91, 351360

Attribution: metoxys (NoOnlineAFKDisconnect), novae (ajane)'s EDF 4.1 outside set · 2026-10-16

Voice chat looks for a microphone with call waveInGetNumDevs (WINMM) at 3F0E96

Evidence: static · Build: steam-57aab039 · Fact ID: voice-chat-device

Voice chat looks for a microphone with call [waveInGetNumDevs] (WINMM) at 3F0E96; VoiceChatAlwaysOff (no author named) replaces it with xor eax,eax so the game finds no recording device.

Basis: the fixed address decoded (import named by rizin)

Addresses (build-specific RVAs unless indicated): 3F0E96

Attribution: VoiceChatAlwaysOff, novae (ajane)'s EDF 4.1 outside set · 2026-10-16

No_Equipment_Lobby_Lag string patchSource: unverified

Evidence: unverified · Build: steam-57aab039 · Fact ID: lobby-lag-jnp

No_Equipment_Lobby_Lag (by Imperial) writes 00 00 00 at A0BE04, over the ASCII string JNP that sits between the script declarations void Chat_Create() and void SetUsedWeapon(); why that cures lag on the equipment screen in the lobby is not explained in the file.

Basis: the fixed address and the bytes around it read with rizin

Addresses (build-specific RVAs unless indicated): A0BE04

Attribution: Imperial (No_Equipment_Lobby_Lag), novae (ajane)'s EDF 4.1 outside set · 2026-10-16
