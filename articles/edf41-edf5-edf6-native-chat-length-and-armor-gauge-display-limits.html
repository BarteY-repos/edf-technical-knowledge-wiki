EDF4.1, EDF5 and EDF6 HUD limits: chat length and armor gauge formatting

ConversionGame technical referencesCross-generation HUDEDF 4.1 / EDF 5 / EDF 6
Technical reference · Source-scoped static analysis with contributor runtime marked; no new R129 game test

The armor meter and short-chat input look similar across EDF4.1, EDF5 and EDF6, but the original executables store their bounds and text differently. The figures below are code/data observations for the named Steam builds, not universal constraints on all later patches or ports.

Native chat-input length

Game Default character limit in the examined build Width-related constant
EDF4.1 32 (0x20) 400
EDF5 32 (0x20) 400
EDF6 16 (0x10) 400

The width value is not a character limit. EDF4.1's code compares a text-area width with a 400-unit baseline; EDF5 has a separate text-input width path; EDF6 stores a bounded window dimension in its input object. As a result, changing only the character count would not necessarily produce a correctly sized visual textbox.

Armor gauge is a display, not the complete gameplay value

In the examined executables the native HUD display truncates the current and maximum armor floats to integers and caps the displayed values at 999,999 (0xF423F). EDF5 and EDF6 additionally compare copies stored within their gauge state. EDF5's bar fill still uses the underlying float ratio, so a capped label does not imply the combat model itself is capped at that number.

Game-specific storage differs; EDF5's soldier keeps maximum and current HP in separate floats, while EDF4.1's displayed values are fetched through its HUD getter. A higher gameplay HP value and a six-digit printed value should not be read as contradictory evidence.

Vehicle aim lines and visibility

In all three source corpora a cooldown state can suppress a vehicle weapon's aim line. The exact cooldown fields differ (EDF4.1 +0xAB0, EDF5 +0xB40, EDF6 its own draw logic), so copying one game's address or gameplay-state offset to another generation would be incorrect. The available sources do not establish one unified color rule for every vehicle weapon.
