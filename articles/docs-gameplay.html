Overview

The behavior of EDF enemies and vehicles comes from more than a model and a script name. Native class state machines, object trees, spawn ownership, animation controllers, collision/physics and weapon emitters can all change between games.

Compatibility model

Treat each port as an integration of resource identity + class behavior + state/animation + physics + weapons + mission usage. A source-only builder PASS proves none of these by itself. Prefer the scoped, already tested behavior where available; classify speculative adapters as such.
