Navigation

UniversalDocumentationNavigationEDF 4.1EDF 5EDF 6
Reference index · Curated reference derived from linked articles; no new game runtime

Overview

Navigation defines traversable space and route candidates, which may not match either the visible terrain or the physical collision. Converting an EDF4.1/EDF5 map while keeping unrelated EDF6 donor nav data can produce correct visuals but incorrect AI paths.

Generation distinctions

The studied NVMD layout contains a v0x120 EDF5 profile and v0x130 EDF6 profile with different B-section record widths. Do not reuse the EDF5 record stride. The separate EDF4.1 R1D 4971-footprint reconstruction remains a research limitation, not an already reproduced output.
