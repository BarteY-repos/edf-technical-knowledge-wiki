EDF6 weapon synchronization — 1,315-configuration atlas

EDF 6Engine RE & NetworkingWeapons
Technical reference · Exact static source corpus evaluation; game-runtime unverified

This reference lists all 1,315 active WEAPONTABLE weapon configurations with a nonempty AmmoClass in the examined EDF6 vanilla data corpus. It is a static evaluation of reachable star-correlated initial-fire policies, not a capture of 1,315 weapons fired in multiplayer. Each row originates from the preserved per-configuration source CSV, not an inferred generic class rule.

The atlas complements the explanation of direct and batched synchronization and the detailed 15 subtype1/direct switchers, rather than repeating those articles.

Read the codes before interpreting a row

Code Actual initial-fire transform ownership
D+1 Direct subtype0, sender-supplied full shot transform
D0 Direct subtype0, sender orientation plus receiver-local translation
D−1 Direct subtype0, fully receiver-local shot transform
B1 Subtype1, six-Weapon-update batched, receiver-local shot construction

A slash (/) means multiple reachable configurations depending on correlated star values; it does not mean all listed policies are active simultaneously. The result is independent of the later NetworkBullet selector and does not predict exact projectile trajectory or damage synchronization by itself.

Source and sample boundary

  • Source game: EDF6, studied vanilla WEAPON.zip and exact EDF.dll build (SHA-256 0d5092393a1b9d8f1b75b0c93d8a8f65615a36a92c46e40349c2b66c733d0916).
  • Source inventory: 1,839 SGO entries, 1,833 individual weapon/config DSGOs, 1,564 WEAPONTABLE rows; 1,315 active rows are included here.
  • Exact per-weapon source: EDF6_ENGINE_RE_WEAPON_STAR_POLICY_ENVELOPE_V1_2026-09-28.csv, SHA-256 10e379c0dc176a27ed12431fa82f8b92dbf89488a76f17692ea0dbf131092644. Its original bytes are also present in the ZIP under reference/EDF6_WEAPON_STAR_POLICY_ENVELOPE_V1.csv.
  • A complete static run evaluated approximately 2.9 million correlated reachable parameter states. This table gives the set of reachable policy labels, not every star state or the activation threshold for each alternative.
  • No new Windows/EDF6 paired-client runtime test was performed in this wiki edition. Newer game builds, changed SGO configurations and modded weapon tables are not covered automatically.
