EDF5 mission lists: original 110/111, converted 112/111 and target 112/112 are different data sets

ConversionGame technical referencesMissions / provenanceEDF 5EDF 6
Technical reference · Source static evidence with unverified behavior labelled; no new in-game R133 test

Three counts can all appear in project documents without describing the same file set. The original EDF5 mission lists have their own offline/online membership. Later EDF5-derived content was expanded for an EDF6-compatible mission pack, and a still later layout intentionally assigned the same number of progress slots to both modes.

A source-sensitive comparison

Evidence corpus Base OFFLINE Base ONLINE Meaning
Original EDF5 active LIST tables, as counted in R37 source census 110 111 Original mode-specific membership, with a 112-ID union
Historical converted R41 EDF5-content pack 112 111 Expanded offline list, with original online-only IDs also present offline
Later EDF6-compatible shared-progress target 112 112 Intentionally identical ordinal axes for save-progress compatibility

The 112 original base-union IDs are not the same as 112 original offline rows. Tutorial M000 was originally OFFLINE-only. M082 and M083 were originally ONLINE-only. Their presence in a later converted offline table does not retroactively change the original EDF5 shipping LIST.

DLC membership is separate: 15 DLC1 and 14 DLC2 missions, bringing the distinct primary shipping corpus to 141 scripts (112+15+14). The source census counted 335 BVM files overall, but this included 10 nonshipping source orphans, 126 EDF4.1-subtree files, 56 TEST files and two TGS/demo files. A 145-script stress set is likewise not the shipping mission count.

Why the distinction matters

A save system can attach clear marks to mission ordinal instead of to a filesystem Mxxx name. A port that changes the list membership or row order without translating save progress can attribute a completion to the wrong mission. Conversely, a converted mission-list table is useful as a study/reference order but is not proof that the untouched original EDF5 OFFLINE list had exactly those rows.

Other resources—name tables, image RABs, CONFIG.SGO and each mission's script—must be compared separately. A valid script ID alone does not prove it is offered in every mode.

Evidence: EDF5 original source LIST census edf5/mission-vm.md, facts bvm-corpus-335, bvm-shipping-141, bvm-orphans; historical converted and shared-progress versions independently recorded in the wiki. Counts are not merged into a single invented universal list.
