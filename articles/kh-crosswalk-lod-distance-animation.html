Distance-based level of detail and distant animation rate (key: AnimationModel, InsectBase, HumanBase)

  • edf5: mesh LoD walk in the AnimationModel draw 3AEF60 (threshold = SGO distance squared); pose-job skip N = 1/4/8/16 in InsectBase 261210 and HumanBase 2EBD30 (humans only with SGO flag human_frame_skip_enable); no runtime impostor | ref: edf5/models.md#animationmodel-lod-select, edf5/models.md#insect-pose-job-skip, edf5/models.md#human-pose-job-skip, edf5/models.md#no-runtime-impostor | evidence: static
  • edf6: same pose-job skip for InsectBase, bands scaled by SGO key insectbase_AnimationLodAdjust; mesh LoD distances are SGO data, consumer not found; LOD* classes are the lod_capture bake tool | ref: edf6/enemies.md#insect-animation-lod-adjust, edf6/enemies.md#mesh-lod-sgo-data | evidence: static
  • edf41: same AnimationModel LoD selector (322E40), plus a debug script command set_lod_distance_scale with seven load-time scale globals; no animation skip found; LOD* classes are a debug viewer | ref: edf41/rendering.md#lod-distance-scale-command, edf41/rendering.md#lod-character-selector | evidence: static
  • Differences noticed: EDF 4.1 has the distance-scale command and no animation skip; EDF5 and EDF6 have the skip (EDF5 humans gated by an SGO flag, default off) and no scale command. Thresholds are squared distances in all three. None of this was run in game.
  • Confidence in the mapping: medium (same selector shape in all three, found by separate disassembly)
  • Added: 2026-11-06 src: novae (ajane)
