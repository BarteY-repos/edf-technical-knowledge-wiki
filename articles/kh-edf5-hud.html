Armor gauge (HUiHudPowerGuage)

The gauge text is (int)cur " / " (int)max, read from the soldier's floats +0x1FC (current) and +0x1F8 (max) (…

Evidence: static · Build: steam-5d11de53 · Fact ID: armor-gauge-cap

The gauge text is (int)cur " / " (int)max, read from the soldier's floats +0x1FC (current) and +0x1F8 (max) (agrees with radar.md's GameObjectBase HP fields), truncated at 4CC78C / 4CC790, and capped at 999999 by mov eax,0xF423F at 4CC798 and four cmp/cmovg on that eax (cur, max, and the stored copies [rbx+0xAE0] / [rbx+0xAE4]), so one imm32 at 4CC799 raises all four (BlueAmulet's hard-coded method writes the same address). The bar fill is the uncapped float ratio.

Basis: FevGrave's Ghidra notes; anchor unique

Addresses (build-specific RVAs unless indicated): 4CC78C, 4CC790, 4CC798, 4CC799

Attribution: FevGrave (ArmorDisplayCap; offset method credited to BlueAmulet), novae (ajane)'s EDF5 outside set · 2026-10-16

Vehicle weapon aim line

At 3ABDD4 cmp dword rbx+0xB40,0 / jg hides the line while the weapon cools down

Evidence: static · Build: steam-5d11de53 · Fact ID: aim-line-cooldown

At 3ABDD4 cmp dword [rbx+0xB40],0 / jg hides the line while the weapon cools down; the patch also keeps the game's override test test byte [rbx+0x111C],1 (blocked) and the "bad-state" path at 3ABDE6 ([rbx+0x11EC]). Line color floats at [rcx+0x114], +0x118, +0x124, +0x128 (ready = the patch's vanilla red 0, 0, 0.5, 0.5). metoxys's WeaponAimLineContextual keeps the line during cooldown in yellow (white as an option).

Basis: the patch's anchor and code

Addresses (build-specific RVAs unless indicated): 3ABDD4, 3ABDE6

Attribution: metoxys (WeaponAimLineContextual), novae (ajane)'s EDF5 outside set · 2026-10-16

Chat

Chat limits: the character limit is mov dword rbp+0x48,0x20 at 4FCF35 (imm byte at 4FCF38, default 32)

Evidence: static · Build: steam-5d11de53 · Fact ID: chat-limits

Chat limits: the character limit is mov dword [rbp+0x48],0x20 at 4FCF35 (imm byte at 4FCF38, default 32); the text input width is mov r8d,400 at 495468 (imm32 at 49546A), after shl ecx,2 at 495465, which BlueAmulet's IncreaseChatLimit replaces with xor ecx,ecx (width 680, limit 128 in the file).

Basis: the fixed addresses decoded

Addresses (build-specific RVAs unless indicated): 4FCF35, 495465, 495468

Attribution: BlueAmulet (IncreaseChatLimit, inspired by Souzooka's), novae (ajane)'s EDF5 outside set · 2026-10-16

The chat word filter starts with cmp word rbx,0 / jnz at 3EF7A0 (the same bytes as in EDF 4.1)

Evidence: static · Build: steam-5d11de53 · Fact ID: chat-filter

The chat word filter starts with cmp word [rbx],0 / jnz at 3EF7A0 (the same bytes as in EDF 4.1); BlueAmulet's RemoveChatCensor jumps over it (EB 6E).

Basis: the patch's anchor

Addresses (build-specific RVAs unless indicated): 3EF7A0

Attribution: BlueAmulet (RemoveChatCensor), novae (ajane)'s EDF5 outside set · 2026-10-16
