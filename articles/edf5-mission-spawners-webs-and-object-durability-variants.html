EDF5 mission objects: teleport anchors, anthills, spider webs and set-piece SGOs

EDF 5Game technical referencesMap objects / missions
Technical reference · Source analysis only (unless a source fact is contributor-verified); no new EDF runtime test

EDF5's native object catalogue includes mission scenery, destructible props, spawners and event effects. Their SGO class and numeric durability settings are not automatically enemy health.

Native class / SGO Raw SGO durability Source interpretation
GeneratorPoll e505_generator 1250 Teleport Anchor

GiantAntEgg 1 Egg and spawn-related scene objects
CaveWall rockl, RockM 200 Cave/rock props, not enemy HP
EDFDoor01 200 Event animation door
shootingtarget 100 Shooting-range target

DeiroiFallEffect, DemoAirStrike, DemoIndirectFire and EventParticle in the same source catalogue have no durability field; these are effects or event objects, not ordinary enemies. Likewise the size number in a SpiderNet filename does not directly encode durability: the source explicitly groups three size-labelled web SGOs under the same 2400 value.
