Settings menu framework (key: HUiHQGameSetting, HUiLayout)

  • edf5: menu screens are ui::HUiLayout subclasses built from layout SGOs; Game Settings is HUiHQGameSetting | ref: edf5/ui-menus.md#hui-layout-framework, #gamesetting-rows | evidence: static
  • edf6: the same RTTI class names, COMMON.CFG, MainScript.as and OptionPlayer_* keys are present in EDF.dll; no addresses yet | ref: edf6/ui.md#settings-classes-present | evidence: unverified (as a mapping) | tried: string/RTTI counts only
  • edf41: none of the HUiHQ* classes or HUiLayout; UiCommon_KeyConfigUtil, COMMON.CFG, MainScript.as present | ref: edf41/ui.md#settings-framework-differs | evidence: static (absence by string search)
  • Differences noticed: EDF 4.1 uses a different menu framework; EDF5 and EDF6 share names.
  • Confidence in the mapping: edf5 to edf6 medium (names only); edf5 to edf41 none for the classes.
  • Added: 2026-10-14 src: novae (ajane)
