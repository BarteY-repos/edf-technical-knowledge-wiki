EDF6 resource loading, ModeList and MissionPack identities

UniversalDocumentationResource LoadingEDF 4.1EDF 5EDF 6
Reference index · Curated reference derived from linked articles; no new game runtime

This section concerns what the game loads and how it identifies resources, not a guide to any particular mod loader.

Stock-game boundary: A native EDF6 MissionPack identity, mode, resource name or archive lookup is an observation about game-side data. Injecting additional packs through a third-party loader, substituting assets or extending the pack namespace is an additional mechanism; the game's native metadata alone does not establish that this extension works in an unmodified executable. References to earlier tooling investigations are included only for their resulting game-side behavior and failure evidence.
