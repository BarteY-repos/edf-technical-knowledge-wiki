EDF6 mothership cores: open-state timers and Genocide Cannon parts

EDF 6Game technical referencesGameplay & AI
Technical reference · Native-data and static code observations; no new in-game runtime test

A giant EDF mothership is not one undifferentiated object. In the examined EDF6 build, its hull, large Genocide gun, small Genocide gun and core states map to distinct classes and data paths. A field on one of these classes should not automatically be attributed to the entire ship.

GrandMothership core opening

The source's static instruction audit finds a normal core-open state that ends after its state-time counter crosses 0x708 = 1800 frames (30 s if the counter advances at 60 Hz). An object-message handler covers the related state transition. A separately documented EDF6_GrandMotherShip_EX patch makes object action 100 (0x1000000D message) set an open-state byte so the core stays open until a later explicit close.

The sustained-open override is patch-added behavior, not evidence that the original GrandMothership always keeps its core open on action 100. Equally, the 1800-frame threshold is not automatically a fixed 30-second wall clock in all gameplay conditions.

Genocide Cannon is not a single untyped projectile

Main hull UfoMother511 Separate parent identity and body paths

These are static SGO/RTTI observations for the named EDF6 511 family. They do not prove which actor ID is assigned as the attacker to the eventual hit. The surveyed source did not close the large cannon's actual firing site; it may be the gun part or another owner that performs the hit registration.

Distinguish animation, hit and explosion

The existence of RocketBullet01 in the large cannon SGO is not proof that a Genocide hit in every earlier EDF4.1 conversion runs a particular effect, death explosion or network event. Firing script, projectile class, impact-effects, and object destruction are distinct chains. The EDF4.1-to-EDF6 Genocide Cannon missing-explosion symptom must remain a port/runtime observation, not a proven fault in a stock EDF6 511 cannon.
