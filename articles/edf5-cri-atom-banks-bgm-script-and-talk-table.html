EDF5 sound system: CRI Atom banks, mission BGM and unscripted NPC chatter

EDF 5Game technical referencesAudio and dialogue
Technical reference · Source-backed static analysis with explicitly scoped contributor tests; no new R125 runtime

EDF5's surveyed Windows build uses CRI ADX2 / CRI Atom, with the playback implementation linked into EDF5.exe and a WASAPI output path. This is not evidence that EDF4.1 sound assets can be copied into EDF5 unchanged. Bank names, cue references, source voice variants and text/subtitles must be treated independently.

Bank and cue organization

Resource Original logical path
Music APP:/SOUND/ADX/TIKYUUX_MUSIC.ACB
Effects APP:/SOUND/ADX/TIKYUUX_SE.%LOCALE%.ACB
Atom settings APP:/SOUND/ADX/TIKYUUX.ACF
Voices app:/sound/adx/tikyuu5_voice.%LOCALE%.awb and related banks

A global SoundController owns the active music playback. Music from BVM and menu scripts eventually reaches a shared play function. A cross-fade stops or fades the prior handle, releases it, plays a new cue and sets the fade-in duration. The native BVM calls in the studied scripts are 300 PlayBGM, 301 FadeOutBGM, 302 FadeInBGM, and 303 for a seek/start-offset variant. A survey of 141 scripts found 846 calls to 300, 747 to 301, 99 to 302 and six to 303. These are call-site counts, not the number of unique tracks.

The NPC voice tables are not dialogue text

The examined EDF5 dataset includes 20 talk SGO files, 1464 talk tables (135 empty), 10,792 entries and 5402 distinct audio cues. A table entry carries the cue, animation, selection weight, bit-mask condition, conditional numeric window and possibly a reply table. The manager selects a weighted entry, applies a speaker variant and schedules it through one of its channels.

Unlike EDF6, EDF5 has no general NPC chatter transcript or corresponding edf6_voicetable in the surveyed resources. A small set of quick-chat UI messages pairs display text with voice cues, but ordinary soldier remarks' spoken words are in audio. A cue appearing in the sound bank therefore cannot automatically be treated as a subtitle identifier.

The TalkManager updates four channels. While a line is playing it reduces a music-volume factor toward 0.3, restoring it toward 1.0 after speech stops. The precise interpretation of that controller float as the BGM multiplier is a static inference, not a separately captured audio measurement.
