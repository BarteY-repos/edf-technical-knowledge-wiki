EDF5 Silver Man: boss limb durability, meteor variants and source limitations

EDF 5Game technical referencesBosses / health
Technical reference · Source analysis only (unless a source fact is contributor-verified); no new EDF runtime test

The Japanese bestiary places Silver Man / Nameless (e516_biggreyboss) in a spoiler-fold within its Archelus page, rather than under a separate heading. Headings-only scraping can therefore miss the entry and wrongly report that it is absent.

Component or attack object Reported source/bestiary baseline
Main body 32000
Upper arm 2400
Forearm 1600
Thigh 1800
Shin 1200
Large meteor 336
Medium meteor 168
Small meteor 84

The meteor values were cross-checked with the corresponding e516_biggreyboss_meteor_* SGOs. The Japanese page describes 0.7× damage-through to the body from hit limbs and a drop-rate convention equivalent to 100 items. Those additional figures are source attributions, not newly runtime-measured thresholds.

Japanese community names (for example 銀の人 and かの者) are not identical to official English localization: the English statistics counter identifies the boss as Silver Man. The internal class name Humanoid_BigGreyBoss does not imply a common player-facing name either.

Sources: edf5/object-classes.md, atwiki-silver-man-spoiler-fold, kill-counter-names, sgo-humanoid-biggreyboss-32000. This page contains EDF5 final-boss spoilers.
