Evidence: static · Build: steam-57aab039 · Fact ID: ufomother301-state-rng-sound

Part state machines: each part has a StateMachineTable::Agent (BigCannon, Panel and the Cannon's rocket machine at +0xB00, the Hatch at +0xCA8, the Cannon's beam machine at +0xD40) and a record {float time, int frames} (+0xAD0 / +0xAD4; beam +0xD10 / +0xD14; Hatch +0xC78 / +0xC7C; hull main +0xB00 / +0xB04); [agent+0x28] points to the record, [record+8] back to the agent. A state switch (BigCannon 257D00, Cannon 25B110, Panel 25DC00, Hatch 25C1B0, one template) runs the old state's phase 2, zeroes the whole record, then the new state's phase 0; each frame: the base update, [record+8]->tick(phase 1, dt), then time += dt, frames++ (a state entered from another's phase 1 first sees frames = 1). dt is seconds ("M"), frames at 60 FPS. RNG: x = x * 0x5D588B656C078965 + 0x269EC3, r = (((x >> 32) * 10000) >> 32) * 0.00010001 in [0, 1]; the parts' state +0x210 (position-hash seeded), a global C64A08 for effect scatter; 51B7C0(out, axis, minAngle, maxAngle, rng) gives a unit vector at a uniform angle in [min, max] from the axis and a uniform azimuth. Sound and effect calls: 3E8150(sound manager [CC8508], &desc, cue) resolves a cue into a 0x40-byte descriptor (+0x10 cue id, -1 none), 3E3F20 plays a descriptor once at a point, 3E85C0(&desc, &pos, &handle) plays and returns a handle (stopped by 1675C0(&handle)), 3E83F0(sound manager, &pos, cue, &handle or 0) plays by name; effects (manager CC8500): 1B16B0(fx, pos, dir, size) a fire burst (火炎_01.dds), 1B1BA0 smoke and fire, 1B2070(fx, pos, dir, size, 1.0) a directed explosion, 1B2AB0(fx, pos, dir, size, k) a big explosion (several 1B1BA0 plus a radial burst, internal 100 / 300 / 600), rendering.md#edf41-effect-generators; 337A60(ragdoll +0x7A0, out) a point inside the part's physics shell bounds ("M"). Sound throttling: the hull's six counters +0xBB8 count down each frame; before certain sounds a part does old = slot; slot = 16; play if old == 0, so each is played at most once per 16 frames ship-wide: slot 0 panel start, 1 panel laser, 2 panel cannon, 3 cannon charge, 4 cannon fire, 5 cannon beam.
