EDF6 native Engine RE: 145 object and subobject fields

EDF 6Engine RE & Networking
Technical reference · Exact build static evidence; not a gameplay runtime qualification

This table preserves the full struct_fields.json subset of the build-specific native Engine RE database. Fields describe in-memory object layouts, not serialized file schemas or network message offsets. An offset is measured from the named object/subobject base. Never add offsets from different types without accounting for embedded-object bases. PROVEN/HIGH are source confidence labels grounded in static evidence; neither is a new game-runtime test.

Binary: analyzed EDF6 EDF.dll SHA-256 0d5092393a1b9d8f1b75b0c93d8a8f65615a36a92c46e40349c2b66c733d0916. Source authority: the R17 Engine RE database (archive SHA-256 93419d55b395c9452e1b23fbccdb37baba3cdb9c4c63f71bac5e31e809e86784). Companion: 336 native symbol RVAs and unpromoted site evidence. Cross-object boundary reminders

For example, BulletBase+0x130 is final per-projectile RNG state, whereas Bullet InitParam+0x1A0 is the value transferred during construction. A replicated-state subobject at BulletBase+0x140 has its own relative fields. Likewise, a bitmask for NetworkBullet selectors is not a general declaration that every derived projectile supports each selector. See projectile RNG class consumers and NetworkBullet selector semantics.
