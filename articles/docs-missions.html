Missions

UniversalDocumentationMissionsEDF 4.1EDF 5EDF 6
Reference index · Curated reference derived from linked articles; no new game runtime

EDF6 mission gameplay uses MISSION.AC and MISSION.RMPA alongside a mission LIST entry, localization, progression state and referenced assets. Mission resource and map resource families are not interchangeable: mission RMPA holds mission-local route/spawn objects; map resources have different structure and ownership.
