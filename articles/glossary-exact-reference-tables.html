Fail-closed reference

When exact semantics are not known:

  • preserve unknown data where safe;
  • refuse destructive rewrite where preservation is impossible;
  • keep third-party behavior explicitly attributed;
  • keep source-only/offline evidence distinct from runtime evidence;
  • record negative evidence so rejected treatments are not rediscovered as “new” fixes.
