Observed native map-model shader/material families

This is a table of ordinary MDB material families observed in EDF6 model assets stored in map resources. These are model/material observations, not FieldRender/FMEP terrain rules. Counts are material occurrences, not unique shader binaries.

The value of this table is breadth: it shows that EDF6 simultaneously ships newer snd_BRDF_Map_* materials and older snd_Map_* families with specular_pow, light_smooth, reflect/spec packed textures and multiple material ABI variants. It is not a claim that these are all EDF6 shaders.

Practical conclusions

  • Reflection is a capability description, not necessarily a real-material schema. A reflected variable can be absent from a native MDB material, and native parameter order does not necessarily match cbuffer declaration order.
  • Legacy and BRDF families coexist. Do not infer that specular_pow is obsolete merely because newer BRDF shaders exist.
  • The same shader name can appear with more than one material ABI in legacy content. Preserve imported material structure unless a profile is specifically known.
  • Sampler order in MDB is not always shader-register order. The selected Build/Window/Parallax/DirtScroll/Signboard families provide direct examples.
  • SND_CHARA_BASIC itself was not part of these map-model corpora. The observed material set supports the general statement that legacy-style material contracts survive in EDF6, but does not answer the character-shader compositor question.
