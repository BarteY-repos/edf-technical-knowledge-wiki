EDF5 Erginus King: a retained EDF4.1 asset that the EDF5 campaign does not spawn

EDF 5Game technical referencesUnused / retained assets
Technical reference · Source analysis only (unless a source fact is contributor-verified); no new EDF runtime test

EDF5's Root.cpk includes monster501_king and its supporting resources. It uses Monster501 as does ordinary Erginus, but has different model, CAS and ragdoll assets, a source durability of 64000 compared with Erginus's 32000, an enlarged camera distance and an attack setting 1500 compared with 1000.

That makes it a genuine retained resource; it does not make it an EDF5 main-game encounter.

The exact source scan found monster501_king in the EDF4.1 mission subtree stored within EDF5's archives (mission/edf4.1/mp004/mission.bvm). No EDF5 campaign or either EDF5 DLC Mission Pack script in that corpus references it. This is a narrowly scoped negative mission-reference finding, not proof that no mod or undocumented external script could spawn it.

An earlier inventory row labelled Monster501_King “used in official missions.” Its broad scan included the EDF4.1 subtree. The later explicit source-provenance scan corrects that misleading statement for EDF5 release missions. The model's color in gameplay was not established from these resources.

Source: edf5/object-classes.md, fact edf5-erginus-king-unused (static SGO and full mission-reference scan); raw row sgo-monster501-64000 corrected by this later evidence.
