Team id, HP, position, invincibility (key: RTTI SoldierBase / GameObjectBase)

  • edf5: team id dword on the object, HP, position; set_invincible flag | ref: novae (ajane), edf5/radar.md#gameobjectbase-fields | evidence: static (MODE 1 and the team trick verified in game, edf5/combat.md#set-invincible-bit, #team-switch-restart-crash)
  • edf6: team id, dead byte, HP, position, invincible flag | ref: edf6/combat.md#team-id, #object-target-fields, #invincible-flag | evidence: static
  • Differences noticed: every offset moved (for example the position is +0xA0 in EDF5's GameObjectBase and +0x90 in EDF6's fields). Same mechanisms: one dword team id, a flag that the damage function honors unless the hit is forced. A field-by-field map (HP, team, pad index, player link, flags, dead flag, scene children; soldier vtables, update slot, message vfuncs) is edf6/combat.md#edf5-edf6-object-fields, #soldier-vtables-update, #message-vfuncs (added 2026-10-28).

TeamManager and team member sets (key: RTTI TeamManager)

  • edf5: global, CRITICAL_SECTION at +8, teams at [+0x38] (0x38 each, count [+0x48]), MSVC std::set per team | ref: edf5/combat.md | evidence: static
  • edf6: the same layout (lock +8, teams [+0x38], 0x38 each, count [+0x48], the same set node offsets), different global | ref: edf6/combat.md#teammanager-layout | evidence: static
  • Differences noticed: none in the layout; only the global and function RVAs.

Lethal hit message (key: the hit-record setup and the base message handler)

  • edf5: record set up, sent as message 0x80000000 | ref: novae (ajane) | evidence: verified in game
  • edf6: record set up, sent as message 0x10000000 through three virtual calls | ref: edf6/combat.md#hit-message | evidence: static
  • Differences noticed: the message id differs; EDF6 also needs forced flags 0x40 / 0x400 for invincible or spot-damage targets.

Weapons and reload state (key: RTTI WeaponBase)

  • edf5: weapons found by 22 class vtables; ReloadType, ammo, reload-left fields | ref: edf5/combat.md | evidence: static
  • edf6: weapons found by RTTI (base class WeaponBase); ReloadType, AmmoCount, ammo, credits-left fields | ref: edf6/combat.md#weapon-reload-fields | evidence: static
  • Differences noticed: EDF6 has more charged reload types; recognizing weapons by RTTI ports better than vtable lists.

Wing Diver energy (key: RTTI PaleWing)

  • edf6 | ref: edf6/combat.md#palewing-energy | evidence: static
