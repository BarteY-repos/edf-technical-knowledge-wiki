EDF4.1 save files: SAVE_DATA, slot folders, mode-specific MST and MAIN.GST

EDF 4.1Game technical referencesNative save formats
Technical reference · Source-scoped static analysis; no R129 gameplay test

The original PC EDF4.1 executable constructs a save tree under the folder string My Games/EDF4.1/SAVE_DATA, with a saveslot%02d folder for each save slot. The documented strings come from the game executable, not from guessed filenames. The base folder is acquired through a Windows known-folder lookup, though the exact shell-folder constant was not resolved in the cited study.

Names visible in the original executable

Name or pattern Role / level of evidence
saveslot%02d Save slot directory name pattern
SYSTEM.CFG Shared system configuration; studied code builds a SYSTEM folder in place of a slot name
COMMON.CFG Save-related configuration name
SYSTEMWIN32.CFG Windows-specific system settings name
TROPHY.DAT Achievement/statistics save name
MAIN.GST The mode's principal game-state resource filename
%ls_M%02d.MST Mode-specific mission progress filename pattern

The .MST filename is assembled using the loaded CONFIG.SGO PackageName and the ModeList row index, not only the visible campaign title. The stock package name is DEFP, so the first mode's progress name becomes DEFP_M00.MST. The MAIN.GST string is read from an explicit ModeList entry.

What this does and does not prove

The source establishes the filename constants, folder pattern and mode-name construction. It does not independently document all bytes inside these save files, all platform variants, or how concurrent writes are handled. The presence of TROPHY.DAT in both EDF4.1 and EDF6 should not be taken as proof that their binary schemas match. In particular, the EDF6 achievement layout has its own game/build-specific documentation.

A modded package can alter PackageName or mode rows, making filename identity a practical compatibility consideration. That is an observation about the game's native storage model, not a guide to editing or bypassing progression.
