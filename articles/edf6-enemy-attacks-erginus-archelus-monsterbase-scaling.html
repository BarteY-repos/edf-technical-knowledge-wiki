EDF6 Erginus and Archelus: MonsterBase attack scaling

EDF 6Game technical referencesGameplay & AI
Technical reference · Static/source-backed community evidence; verified test results identified separately; no R117 native runtime tests

Evidence: Static EDF6 steam-678ccb46 reverse engineering and SGO data in the EDF Knowledge Hub snapshot of 14 November 2026. The equations below describe source attack values, not observed player damage after online and other multipliers.

Why boss speed and boss damage cannot be treated as the same level scalar

MonsterBase stores a current attack record from an attack_setting array. The analyzed record contains the attack name, a speed value, damage values (sometimes a list), an auxiliary scalar and flags. The level setup computes g = L/10, with L the raw object level.

For an attack's animation-event melee hit, the native callback uses the record's first damage value multiplied by g. Its other attack fields may control the contact region, hit flags and attack speed. Speed changes with level only if the SGO speed item is an expression array; plain source floats remain constant.

Erginus: per-hit and per-projectile damage

These are the interpreted data-derived contact values by source attack row. A source speed number (e.g. 1.0 or 1.5) is not an additional damage multiplier unless the attack consumer uses it that way.

Erginus's breath uses an embedded LightningBullet01 projectile. For the observed attack_breath_t row, damage is 12L per fired bullet; for attack_breath_b, 2L. The king version has 18L and 9L. The source did not close the total number of bullets per breath, so the article deliberately avoids a fabricated “total breath damage” figure.

Archelus (Monster504): sparks and contact hits differ

The main attack record's damage item may contain multiple values. Archelus's projectile constructor selects the second entry if present, whereas an animation contact hit uses the first. This is why “attack damage” cannot be one scalar for the entire row.

Attack example Source value
Ordinary spark projectile 1.5L per bullet
Thorn-roll thorn projectile 1.5L per thorn
Thorn-roll contact 2L
_vs_big spark or thorn projectile 10L
_vs_big thorn-roll contact 100L

The e504_monstera_m034_3 variant has lower source values in several attacks; applying the normal Archelus numbers blindly to that variant would be inaccurate.

Speed adjustment and attack intervals

The source-defined optional speed rule for list-valued speed fields is:

attack_speed = min(L × a + b, c), for an item encoded as [b,c,a].

In the inspected Erginus, king and Archelus attack rows the speed fields were ordinary floats, so that particular per-attack speed did not scale with level. Archelus also has an independent monster_base_animation_speed array. For its example [0.8,1.5,0.9,0.01], the corresponding expression is clamp(0.9 + 0.01L,0.8,1.5). This is a separate animation-speed control, not a damage curve.

Archelus's bullet_level_adjust was [1.0,4.0,20.0,400,400] as plain source values. Some byte-level parameter interpretations remain unverified, and the exact attack-interval consumer was not followed fully; they should not be promoted to a complete physics model.

Evidence limitations

  • These are native data and code reads, not full combat sessions at fixed difficulty.
  • The emitter's animation event, projectile count, collision filter and ModeList may alter what a player experiences.
  • A stage-specific enemy asset may have different SGO rows while retaining the same broad family name.
