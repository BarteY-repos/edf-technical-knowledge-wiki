EDF6 enemy attacks: ants, hornets, spider threads and tadpoles

EDF 6Game technical referencesGameplay & AI
Technical reference · Static/source-backed community evidence; verified test results identified separately; no R117 native runtime tests

Evidence: Source-attributed static analysis of the studied EDF6 steam-678ccb46 binary and object SGO records, collated by novae (ajane) in the EDF Knowledge Hub (14 November 2026, revision 54f89cd). These are base attack formulas, not measured damage against a particular player at a particular difficulty. No new EDF6 runtime experiments were performed for this article.

Read the formulas correctly

  • L is the raw game-object level read by the enemy's level setup, not the difficulty name and not the player's armor. Some source records use v = L / 10 instead.
  • Each line is per projectile or per hit, unless explicitly called a volley total. Multi-projectile attacks must be counted separately.
  • Online game modes may multiply a delivered hit according to the hit-record type. Thus these formulas are not necessarily the final on-screen HP loss.
  • Values such as ant_ex_DamageScale, spd_Ammo and dragon_AttackBulletSetting come from each enemy's source asset and can distinguish variants of the same class.

Ants: one class, two different projectile behaviors

Attack Raw source formula Other parameters
Normal ant acid (ant_BulletType=0) max(0.5 × L, 1) × ant_ex_DamageScale per drop min(trunc(L/5 + 1), 16) drops per volley; speed L/400 + 0.4 m/frame; lifetime 180 frames
Queen ant stream (ant_BulletType=1) 0.08 × L × ant_ex_DamageScale per drop speed 1.0; lifetime 240 frames; 90-count initial stream counter, with one bullet emitted per observed firing call
Ant bite 0.5 × L × ant_ex_DamageScale, then animation-event damage_scale Sent through the type-3 hit path, unlike the projectile's type-0 record

The acid path uses a capped bullet-count function; do not multiply its damage by 16 at low levels. At L=10, the count is 3, whereas at L=100, it is capped at 16. giantant04sb has source ant_ex_DamageScale=2.5; the regular recorded value is 1.0. The queen stream's 90-count field is not independent proof that all 90 hits actually land.

The source stores the ant's bullet init parameters beginning at GiantAnt+0x1680; ant_BulletType is at +0x1670 in the examined build. These are version-specific memory offsets.

Hornets: regular needles versus queen needles

Variant Damage per needle Other observed parameters
Normal GiantBee max((L/1.5 − 20/3) × 0.58 + 20/3, 1); equivalently about max(0.3867L + 2.8, 1) Count min(trunc(L/5 + 1), 16); lifetime 180 frames; size 0.2
Queen hornet (insectbase_Type=1) 0.5 × L + 15 1.5× speed multiplier, lifetime 300 frames, size 1.0, blast radius 3.0

The queen is not just a larger normal bee: the code selects another branch with another damage curve. The source analysis found no extra bee damage-scale SGO key in this calculation.

Spiders: thread count and SGO multipliers

The spider thread uses spd_Ammo = [size, speed multiplier, damage multiplier]:

Field Formula / value
Thread damage 0.375 × L × spd_Ammo[2] per thread; the source also contains a lower-bound fallback when the calculated value is nonpositive
Thread speed (L/400 + 0.8) × spd_Ammo[1]
Thread size 0.1 × spd_Ammo[0]
Thread count min(trunc(L/5 + 1), 16, spd_MaxStringCount if present)
Lifetime 300 frames

Ordinary recorded spiders use [1, 1.2, 1]. Queens use [5, 2, 2], doubling the base per-thread damage before any online modifier. The light spider e651_spider01_light has spd_MaxStringCount=3. An additional +0x1958=L field was hypothesized to be bite damage; its consumer was not proven, so that value is not presented as a verified bite formula.

Tadpoles: fireball and bite are independent attack paths

The fireball formula is max(L/3, 1) × B[4], where B = dragon_AttackBulletSetting:

Source variant B=[size, base speed, speed divisor, spread, damage factor] Resulting fireball damage
dragonsmall401 and _hs [0.3, 0.6, 200, 0.1, 0.75] max(L/3,1) × 0.75
redsmalldragon and _hs [0.6, 0.8, 100, 0.1, 1.0] max(L/3,1)
yerrowsmalldragon and _hs [0.3, 0.8, 100, 0.1, 1.0] max(L/3,1)

Volley size is min(trunc(L/10+1),8), projectile speed L/B[2]+B[1] m/frame, lifetime 360 frames and gravity scalar 0.25. The source bite uses L × C[2], with C[2]=1 for all six inspected tadpole assets; an animation event may multiply it further.

How online mode can change the result

The inspected native hit path marks bullets with hit-record type 0, and bites with type 3. In the community's analyzed solo Normal online example, the type-0 insect bullet multiplier was 2.64, whereas the type-3 bite route used 1. These are observations of a specific ModeList configuration, not universal online difficulty multipliers.

Do not infer: a monster's final damage from a single SGO damage value; the engine may generate multiple shots, apply hit-record-specific mode scaling, and run a separate damage-reduction path.
