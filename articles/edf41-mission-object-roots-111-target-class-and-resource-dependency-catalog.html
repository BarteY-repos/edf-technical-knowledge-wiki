What this catalog actually counts

The bounded research corpus contains 111 distinct mission-referenced EDF 4.1 object SGO roots, associated with 325 distinct logical dependency files. It was reconstructed from an audited EDF 4.1 asset/mission collection and the All Forces-derived compatibility reference. This is a cross-generation asset reference, not an official list of every object in the original game.

Interpret the columns carefully: source_root is the SGO identity in the research corpus. The EDF6 compatibility class is the target-side class mapping, not necessarily the original EDF 4.1 native C++ class. Mission refs counts references found in the audited converted mission corpus, not unique original missions, spawn counts, or in-game appearances. Multiple SGO roots may occur in the same mission.

These 325 file identities comprise 175 SGO, 58 SHKT, 45 CAS, 31 RAB and 16 MRAB paths. A single shared model or animation can be referenced by many object variants; the 821 object-to-file edges are therefore not 821 unique files. All 48 weapon-side files are dependencies of mission NPC equipment; their location under WEAPON/ does not imply that the player can equip them.

How to read the dependency families

A single mission actor can require a root SGO plus its model RAB/MRAB, animation CAS, physics SHKT and weapon-side SGO or model. The same dependency may be shared across many actors. A class name alone is therefore insufficient to infer which original animation, collision body, weapon or mission behavior was used.

The dataset is named data/EDF41_MISSION_OBJECT_R6_111_ROOTS_R146.csv in the distributed archive. It lists every root, target class, mission-reference count, logical file count and each logical dependency path. It contains metadata only, not game assets.
