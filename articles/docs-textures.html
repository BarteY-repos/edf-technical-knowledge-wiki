Overview

EDF textures commonly use DDS-family payloads, but format, channel meaning, alpha behavior and sampler binding must all be inspected. A DDS file with valid dimensions can still be incompatible with a shader or a specific resource slot.

Practical constraints

For BC1/DXT1 cutouts, maintain alpha coverage across mip levels when the source asset depends on a binary transparency edge. Do not globally convert all alpha assets to BC1. For mission previews, a valid DDS has to be stored under the named entry derived from LIST field 2 in the base offline/online IMAGE.RAB archives for the studied target profile.
