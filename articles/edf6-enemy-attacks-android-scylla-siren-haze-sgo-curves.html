EDF6 Androids, Scylla, Siren and Haze: DSGO attack curves

EDF 6Game technical referencesGameplay & AI
Technical reference · Static/source-backed community evidence; verified test results identified separately; no R117 native runtime tests

Evidence: Source-attributed static inspection of EDF6 steam-678ccb46 game_object_level / DSGO records in the EDF Knowledge Hub (2026-11-14, 54f89cd). These are asset-defined base attack values, not full end-to-end measured gameplay damage.

The common normalized level and interpolation

In this family, use v = L/10. The common interpolation coefficient is:

q = clamp((v - 1)/29, 0, 1).

Many asset values use lerp(a,b,q) × v. Some BerserkerSettings use (v-1)/29 without clamping. Consequently, treating all enemy growth as capped at v=30 is incorrect.

The Dango formulas show an important distinction: the per-level coefficient may decrease while the total product still increases. Reading only the start/end interpolation endpoints leads to misleading claims about absolute difficulty.

The mission variants _m051, _m118_5 and _rm034 change some source values; a universal Siren attack table would hide this. Some entities, such as nephila (Aranea), have attack logic in code that the cited SGO pass did not follow.

Practical boundaries

These formulas are excellent for comparing which native asset paths control which attacks. They are not a substitute for determining the attack's firing count, collision and target type, online adjustment, and any class-specific code multiplier. Consult native stop/hit filter behavior and the raw enemy evidence appendix before extrapolating a final damage number.
