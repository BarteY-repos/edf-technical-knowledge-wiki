EDF 4.1 — Ui (community source notes)

EDF 4.1Community Knowledge HubGameplay & AI
Source-backed research / case study · Contributed research; per-claim static, verified, unverified; not independently re-tested

This is a source-attributed research appendix, not a chronology or a replacement for topic reference pages. The observations were contributed in the EDF Knowledge Hub export, snapshot 2026-11-14, revision 54f89cd, compiled by novae (ajane).

Read each statement with its evidence grade and exact build. Verified means a reported game test, static means reverse engineering or source inspection without a reported game test, and unverified is a hypothesis. None of these observations was newly tested for this wiki release.

Facts

EDF41.exe has MainScript.as, COMMON.CFG, UiCommon_KeyConfigUtil and the OptionPlayer_RotateSpeed text key, bu…

Evidence: static · Build: unknown · Fact ID: settings-framework-differs

EDF41.exe has MainScript.as, COMMON.CFG, UiCommon_KeyConfigUtil and the OptionPlayer_RotateSpeed text key, but none of EDF5's HUiHQ* settings classes or HUiLayout, so its settings menus use a different framework than EDF5 and EDF6.

Basis: byte search of EDF41.exe (13,896,192 bytes) for ASCII RTTI names and UTF-16 strings; counts only, no disassembly; build id not taken. Searched and absent: HUiHQGameSetting, HUiHQKeyConfig, HUiHQSystemSetting, HUiLayout@ui; present: UiCommon_KeyConfigUtil, COMMON.CFG, MainScript.as, OptionPlayer_RotateSpeed

Attribution: novae (ajane) · 2026-10-14

EDF 4.1's between-mission menus have only basic mouse support: moving the mouse moves the current selection a…

Evidence: verified · Build: steam-57aab039 · Fact ID: menu-mouse-basic

EDF 4.1's between-mission menus have only basic mouse support: moving the mouse moves the current selection as if an arrow key or d-pad direction were pressed; there is no free pointer like EDF5's and EDF6's menus have.

Basis: novae (ajane)'s play experience, reported 2026-10-26; not looked at in EDF41.exe; consistent with settings-framework-differs (a different framework from HUiLayout)

Attribution: novae (ajane) · 2026-10-26

The HQ background (UiBG) camera: its projection 419A70 - 51B230 is a right-handed perspective (near 0.01, far…

Evidence: static · Build: steam-57aab039 · Fact ID: uibg-camera-edf41

The HQ background (UiBG) camera: its projection 419A70 -> 51B230 is a right-handed perspective (near 0.01, far 4000) with the vertical field of view from [this+0x90]; the UiBG setup writes 0.96 rad (0x3F75C28F) to +0x540 at 40918F and the position +0x530 defaults to (0, 0, 0, 1) (409199..4091A7), replaced by the SGO's position when present (4091B1..4091E7; Menu_BG01.sgo has none). The geometry fits: the farthest BG_Stripe at z = -31.03, 58.04 x 32.66, exactly fills that frustum. Unlike EDF6's flat UI models (edf6/ui.md#ui-skin-model-transform). EDF 4.1's main game HQ music is BGM_E4S02_EDFHonbu (its default too, 3475F0), pack 1 BGM_Sinkou_intermission, pack 2 BGM_Sinkou_taisenmenu (ModeList item 3 of each package.sgo).

Basis: the author's reading against EDF41.exe; the +0x540 / +0x530 writes re-read with fn.py here (KH chat 47; the author cites 409190, one byte into the 0.96 store)

Addresses (build-specific RVAs unless indicated): 419A70, 51B230, 40918F, 409199, 4091A7, 4091B1, 4091E7, 3475F0

Attribution: hajisensai, All Forces source docs/mission-list-re.md (round 24, backfill KH chat 47) · 2026-11-07

Original research (pinned): hajisensai — docs/mission-list-re.md

EDF 4.1's kill counters (the names an enemy SGO's game_object_kill_counter gives

Evidence: static · Build: steam-57aab039 · Fact ID: kill-counters-edf41

EDF 4.1's kill counters (the names an enemy SGO's game_object_kill_counter gives; EDF41.exe holds a table of 24 names around A36D20, which is NestKillCount): Hector (HECTOR301, HECTOR401) HectorKillCount, Four-Legged Fortress (ALIEN4LEGTANK301) 4LegTankKillCount, Deroy (DEIROI401 and variants) DeiroiKillCount, Protector (ALIENTRAILER401) AlienTrailerKillCount, Argo (UFOROBO401) UfoRoboKillCount, the Earth Eater's core (UFOMOTHER401_COREPANEL, DLC _DLC_COREPANEL) MotherShip401KillCount (one counter for both names: Japanese "アースイーター撃破数", English "Brains Defeated"), Mothership (UFOMOTHER301) MotherShip301KillCount, large carrier (UFOCARRIER401) Carrier2KillCount, carrier (UFOCARRIER301) Carrier1KillCount, flying vehicle (UFO401, DLC UFO401ACE) UfoSmall401KillCount, drone (UFO301) UfoSmall301KillCount, red drone (UFO301ACE) UfoSmall301AceKillCount, big dragon (DRAGONBIG401) BigDragonKillCount, dragons (DRAGONSMALL401, REDSMALLDRAGON, YERROWSMALLDRAGON, DLC _HS) DragonKillCount, underground nest (ANTHILL301; DLC UG / UGMP02 / LARGEMP02) NestKillCount, DLC ants (GIANTANT04 ...) GiantAntKillCount, DLC queen (GIANTBEEQUEEN02) GiantBeeQueenKillCount, DLC Retiarius (NEPHILA02L / 03L) NephilaKillCount. EDF6 reuses some of these names for other enemies (edf6/battle-record.md#kill-counter-name-reuse).

Basis: A36D20 read with fn.py here (KH chat 47: UTF-16 NestKillCount); the unit-to-name table is the author's, from the 4.1 SGOs

Addresses (build-specific RVAs unless indicated): A36D20

Attribution: hajisensai, All Forces source docs/kill-counter-re.md section 5 (round 24, backfill KH chat 47) · 2026-11-07

Original research (pinned): hajisensai — docs/kill-counter-re.md
