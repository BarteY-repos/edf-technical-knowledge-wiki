EDF5 allied NPC soldiers: SGO weapon loadouts and role names

EDF 5Game technical referencesAllied NPCs / weapons
Technical reference · Source analysis only (unless a source fact is contributor-verified); no new EDF runtime test

EDF5's NPC soldier SGOs describe weapons in soldier_load_weapon, pointing to weapon/ and an Ai* weapon SGO. The source census lists 22 carried NPC weapon definitions. Broad runtime classes are shared with player soldiers: AssultSoldier for Ranger-style AI, PaleWing for Wing Diver-style AI, and HeavyArmor for Fencers.

Fencer definitions can carry two weapon definitions, including AiHeavyShield01; Grim Reaper variants additionally name AiHeavyDash01. elite corresponds to the Spriggan group, _s_ to Sarge's squad, whose leader carries AiSoldierLaserRifle02 (Blazer) from offline mission 78 onward in the studied script data.

NPC weapon SGOs contain plain ammunition, damage and reload numbers rather than player weapon star arrays. The original source comparison with the Japanese NPC weapon table found matching values where provided, but also found erroneous English first-pass catalogue labels (e.g. shotgun Rangers called Fencers).
