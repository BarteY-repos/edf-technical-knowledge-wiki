EDF5 NeedleBullet01: stinger model/line geometry, impact and expiration

EDF 5Game technical referencesEnemy mechanics
Technical reference · Source-declared grades; this edition does not add native game runtime testing

Bee stingers in EDF5 are represented by the NeedleBullet01 ammunition class. The research identifies both a line-based draw path and a model draw path, selected by an ammunition custom parameter. They share a physical projectile and impact lifecycle, but should not be mistaken for a conventional dropped model asset.

The native draw geometry

The stinger draws from a bullet-to-render transform: a position and an oriented Z axis. The source reconstructs its segment as position ± (Z direction × 25 × AmmoSize). In the model mode, a uniform matrix scale uses AmmoSize; in the line mode it affects both length and width. Ammo_CustomParameter[0] selects the mode (observed 0 = stretched line, 1 = model); exactly which mode every bee variant uses was not exhaustively verified.

The line's geometry is centered on the collision point. The investigator observed that when a stinger strikes the ground, reducing its size causes the visible tip to disappear below the surface, rather than retract uniformly from the pointed end. That is a reported game observation, not just a mathematical guess.

Fade is a material-and-depth operation

A stuck needle can be faded by changing the alpha of its draw color. Model mode loads a constant RGBA (1,1,1,1) into the draw-utility shader path; line mode uses the ammo color. The source also notes that depth writing must be disabled during transparent fading, otherwise a transparent stinger can still occlude other geometry as though it were opaque. The contributor reported the fading approach as tested, rather than simply reading the call graph.

The model uses the game’s draw-utility color-lighting shader. This is not necessarily the same material configuration as the environment MDB it appears to strike. Impact smoke is spawned separately via a helper and fragment emitter; changing the needle geometry alone will not copy or remove all impact effects.

Stuck state and cleanup

The source identifies a hit flag inside the needle's render subobject and a lifetime at projectile +0x3F8. Once the original lifetime expires, a stuck projectile enters a 300-frame cleanup countdown; an unstuck expired projectile is removed by its own path. The hit flag's precise behavioral interpretation was inferred statically and was not separately reverified in game. The five-second countdown is derived at a nominal 60-Hz update rate, not an independently measured wall-clock promise.
