EDF5 Menu Layouts, Settings Callbacks and UI Notices

EDF 5Community Knowledge HubNative UI & Input
Technical reference · Editorial synthesis of contributor static/game observations; per-claim grades below

Overview

EDF5 settings and UI notices are message-driven native systems. A layout SGO specifies the C++ UI object class and callback names rather than fully describing the screen’s behavior.

Format, API or behavior

ui::HUiLayout subclasses register named callbacks, with game settings implemented by HUiHQGameSetting. A separate notice dispatcher fans event 12 to UI listeners, including UiNotice, which enqueues strings for presentation.

EDF5 menu screens are ui::HUiLayout subclasses created from layout files. The .sgo names the C++ class (xgs_ui_object_class) and the callback names its buttons use; the class registers handlers for those names; the HQ main menu opens its submenus from paths stored in its layout data.

Notice dispatch — static

61E950 enters the UI manager's critical section (+0x60) and calls vtable[+0x18](listener, 12, payload) on every listener in two lists. The 27680 call inside it is an empty debug-print stub.

Version notes and limitations

Use the exact handler names from the relevant EDF5 build; a callback name reused in EDF6 may have different constructor and UI registration behavior.
