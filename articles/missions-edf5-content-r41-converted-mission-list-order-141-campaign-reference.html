Evidence scope: the exact R41_ORDER_BACKGROUND_FIX_AUDIT.json comparison of a converted EDF5-content package. This is a converted MissionPack LIST order preserving an EDF5 mission sequence, not an independent binary read of untouched original EDF5 shipping LIST.SGO. EDF6-compatible later shared-progress lists use a different OFFLINE/ONLINE alignment policy.

TXT indexing and menu-field evidence

The same historical converted package carries SGO v258 localized TXT companion tables for EN, JA, KR, CN and SC in both modes for all three packs. The recorded TXT row count in each language/mode equals its corresponding LIST row count. Titles and descriptions are indexed by the LIST ordinal; merely possessing the correct mission filename is not enough if the TXT table follows a different order.

All six audited converted LIST profiles carry flags=8 for each row in this R41 snapshot. The menu timeline/style pair (fields 6 and 7 in that historical layout) is 0,0; this followed a previous erroneous dystopia-style 2,1 pairing in the converted package. These are snapshot facts, not a universal encoding rule for native EDF5/EDF6 mission types or for a later target LIST schema.

Distinction from the later EDF6-compatible metadata contract

The later EDF6 target deliberately assigns 112 shared ordinals to both base OFFLINE and ONLINE. It includes M000 and M082/M083 on both index axes while keeping separate gameplay mode/difficulty configuration. The original converted R41 reference above is valuable as a source-order oracle, not a drop-in modern save-progress schema. The relevant current target fields and underground flags are documented in EDF5-derived MissionPack03–05 shared progress metadata.

How to read this reference

  • Mission IDs are identifiers, not numeric-sort keys. The position of M082 and M083 immediately before M098 and M099 is observed directly.
  • An absent base ONLINE M000 does not imply the data is missing from the converted OFFLINE LIST.
  • Do not infer mission availability, difficulty balance or clear-state semantics solely from an ID-to-ordinal row.
  • The companion CSV at data/EDF5_R41_CONVERTED_MISSION_LIST_281_ROWS.csv contains the exact six-profile reference in a form that can be searched or compared without parsing the large table.

Underground subset cross-reference

The source-derived underground map and LIST census records 15 distinct cave/EDFRoom missions and their 30 mode-specific ordinals in the later R4 shared-progress converted configuration. This is intentionally not merged into this article’s historical R41 112/111 list: the two configurations differ in whether M000 exists in the ONLINE list.

Native EDF5 source-list counts are not the R41 converted counts

This 112/111 table documents the historical converted EDF5-content MissionPack. For untouched native EDF5, the original source census instead recorded 110 OFFLINE / 111 ONLINE, including offline-only tutorial M000 and online-only M082/M083. An expanded converted OFFLINE list can legitimately include IDs absent from the original OFFLINE mode. The later EDF6 shared-progress system uses 112/112 for a third reason: stable mode ordinals.
