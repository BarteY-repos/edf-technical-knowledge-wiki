Source-backed research / case study · Contributed research; per-claim static, verified, unverified; not independently re-tested

This is a source-attributed research appendix, not a chronology or a replacement for topic reference pages. The observations were contributed in the EDF Knowledge Hub export, snapshot 2026-11-14, revision 54f89cd, compiled by novae (ajane).

Read each statement with its evidence grade and exact build. Verified means a reported game test, static means reverse engineering or source inspection without a reported game test, and unverified is a hypothesis. None of these observations was newly tested for this wiki release.

Build steam-5d11de53

The EDF5 module is EDF5.exe, Steam build, PE timestamp 0x5d11de53 (2019-06-25), image base 0x140000000

Evidence: static · Build: steam-5d11de53 · Fact ID: edf5-build-identity

The EDF5 module is EDF5.exe, Steam build, PE timestamp 0x5d11de53 (2019-06-25), image base 0x140000000; build id steam-5d11de53. It is the only EDF5 build analyzed.

Basis: PE header of the analyzed EXE (the internals reference's preface; novae (ajane)'s copy matches, #user-edf5-exe)

Attribution: novae (ajane) · 2026-10-12

EDF5 MSVC RTTI and Havok code markers

Evidence: static · Build: steam-5d11de53 · Fact ID: edf5-engine-libraries

EDF5.exe carries MSVC RTTI (.?AV… class names), Havok (hkpEntity, hkpMaxSizeMotion, hkpBoxMotion; hk_2015.1.0-r1, Physics2012, physics-havok.md#havok-version) and Umbra visibility objects (umbra::Object, drop-items.md).

Basis: RTTI and strings in EDF5.exe

Attribution: novae (ajane) · 2026-10-12

EDF5 binary analyzed by mission transpiler

Evidence: static · Build: unknown · Fact ID: transpiler-edf5-exe

The EDF5-to-EDF6 mission transpiler project (drop shared by Bartey) analyzed an EDF5.exe of 19,896,320 bytes, SHA-256 3512d2a2e61d532c5d12dc0c5fd1ac61f6743e13349ae21301bb8449dd4bae5f, with umbra_sandlot.dll of 323,584 bytes.

Basis: file inventory in the R37 handoff, section 3.1

Attribution: EDF5-to-EDF6 mission transpiler R37 (Bartey drop) · 2026-08-26

novae EDF5 executable checksum comparison

Evidence: static · Build: steam-5d11de53 · Fact ID: user-edf5-exe

novae (ajane)'s EDF5.exe is byte-identical to the transpiler project's: 19,896,320 bytes, SHA-256 3512d2a2e61d532c5d12dc0c5fd1ac61f6743e13349ae21301bb8449dd4bae5f, PE TimeDateStamp 0x5D11DE53, x64, image base 0x140000000. So the transpiler's EDF5 addresses are build steam-5d11de53. Copy kept in File_Storage/Game_Builds/edf5/steam-5d11de53/.

Basis: sha256sum and PE header of novae (ajane)'s file

Attribution: novae (ajane) · 2026-10-15
