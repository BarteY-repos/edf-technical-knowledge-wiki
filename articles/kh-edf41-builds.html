EDF 4.1 — Builds (community source notes)

EDF 4.1Community Knowledge HubConversion
Source-backed research / case study · Contributed research; per-claim static, verified, unverified; not independently re-tested

This is a source-attributed research appendix, not a chronology or a replacement for topic reference pages. The observations were contributed in the EDF Knowledge Hub export, snapshot 2026-11-14, revision 54f89cd, compiled by novae (ajane).

Read each statement with its evidence grade and exact build. Verified means a reported game test, static means reverse engineering or source inspection without a reported game test, and unverified is a hypothesis. None of these observations was newly tested for this wiki release.

Facts

Evidence: static · Build: steam-57aab039 · Fact ID: edf41-exe-identity

The EDF41.exe analyzed by the EDF41-to-EDF6 project has SHA-256 39b4abf7fe722175741a5e0a154063b27ef8c589a1aa5f86c84853571ac7bda8. Its addresses are written as absolute VAs 0x140... (image base 0x140000000 presumably, as for EDF5; RVA = VA - 0x140000000).

Basis: hash recorded in the project's RTTI audit and HectorBridge verification scripts

Attribution: EDF41-to-EDF6 handoff (shared by Bartey), EDF41_HECTOR_RTTI_AUDIT, carrier audit · 2026-09-06

Evidence: static · Build: steam-57aab039 · Fact ID: user-edf41-exe

novae (ajane)'s EDF41.exe is byte-identical to the one the EDF41-to-EDF6 project analyzed: 13,896,192 bytes, SHA-256 39b4abf7fe722175741a5e0a154063b27ef8c589a1aa5f86c84853571ac7bda8, PE TimeDateStamp 0x57AAB039 (2016-08-10), x64, image base 0x140000000 read from the PE header. Build id steam-57aab039 (Steam, per novae (ajane)). Copy kept in File_Storage/Game_Builds/edf41/steam-57aab039/.

Basis: sha256sum and PE header of novae (ajane)'s file

Attribution: novae (ajane) · 2026-10-15

EDF 4.1's Havok data (ragdoll SHKT) identifies as Havok hk_2014.1.0-r1 (Physics2012-style hkp classes).

Evidence: static · Build: steam-57aab039 · Fact ID: edf41-havok-version

EDF 4.1's Havok data (ragdoll SHKT) identifies as Havok hk_2014.1.0-r1 (Physics2012-style hkp* classes).

Basis: decode of nine Hector SHKT files and map MAD graphs

Attribution: EDF41-to-EDF6 handoff (Bartey), TECHNICAL_HANDOFF_ORIGINAL section 3.1, Havok direct-load audit · 2026-10-01
