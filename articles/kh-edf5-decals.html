EDF 5 — Decals (community source notes)

EDF 5Community Knowledge HubShaders
Source-backed research / case study · Contributed research; per-claim static, verified, unverified; not independently re-tested

This is a source-attributed research appendix, not a chronology or a replacement for topic reference pages. The observations were contributed in the EDF Knowledge Hub export, snapshot 2026-11-14, revision 54f89cd, compiled by novae (ajane).

Read each statement with its evidence grade and exact build. Verified means a reported game test, static means reverse engineering or source inspection without a reported game test, and unverified is a hypothesis. None of these observations was newly tested for this wiki release.

Classes and fields

Decal classes (RTTI): DecalBase, Decal_Splash (type id 0

Evidence: static · Build: steam-5d11de53 · Fact ID: decal-classes

Decal classes (RTTI): DecalBase, Decal_Splash (type id 0; world-aligned box decal; death pools), Decal_SplashProjection (type 1; perspective-projected volume; hit sprays and ant acid), Decal_BulletMark (6), Decal_ExplosionMarks (7), the screen effects FullScreen_Rain/Dust/Fog (other ids, also built on DecalBase), and DecalManager. Constructors: Splash 19DE40, SplashProjection 1A3EB0, BulletMark 19D0F0, ExplosionMarks 19E710, DecalBase 1A1FC0. The type id is at +0x208.

Basis: RTTI and disassembly

Addresses (build-specific RVAs unless indicated): 19DE40, 1A3EB0, 19D0F0, 19E710, 1A1FC0

DecalBase fields: +0x138 dead byte, +0x139 drawn-this-frame byte, +0x13C seconds undrawn, +0x140 age, +0x144…

Evidence: static · Build: steam-5d11de53 · Fact ID: decal-fields

DecalBase fields: +0x138 dead byte, +0x139 drawn-this-frame byte, +0x13C seconds undrawn, +0x140 age, +0x144 lifetime (seconds; every spawner passes 20.0), +0x148 age/lifetime, +0x14C strength (removal rank factor), +0x1E0.. shader parameter blocks, +0x20C dissolve (= 1 - fade value, written each frame), +0x310 bounds (oriented box data used by the overlap test 19F220 -> 5BF340). Fade value: +0x344 (Splash), +0x340 (SplashProjection); BulletMark and ExplosionMarks keep theirs elsewhere (see their update functions 19DA60, 19EF30).

Basis: disassembly and emulator

Addresses (build-specific RVAs unless indicated): 19F220, 5BF340, 19DA60, 19EF30

Life cycle and removal

A spawner builds an InitParam struct (vtable at its start

Evidence: static · Build: steam-5d11de53 · Fact ID: decal-life-cycle

A spawner builds an InitParam struct (vtable at its start; lifetime at +0x28, strength at +0x2C); the constructor copies it, and every constructor ends with RegisterDecal 1A23E0 (this = decal), which calls the manager's eviction function 1A0860 and then links the decal. Per frame the type's update function runs (19E4E0 Splash, 1A45F0 SplashProjection, 19DA60 BulletMark, 19EF30 ExplosionMarks): age += dt; once age > lifetime the fade value is multiplied by 0.95 per frame until it is below 0.05, then 617B30 (kill) is called. The same functions delete a decal that went undrawn for more than 1.0 s (+0x13C).

Basis: disassembly and emulator

Addresses (build-specific RVAs unless indicated): 1A23E0, 1A0860, 19E4E0, 1A45F0, 19DA60, 19EF30, 617B30

Attribution: novae (ajane), internals section 10 · 2026-10-12

The 1-second undrawn deletion is real: novae (ajane) saw decals vanish when they looked away

Evidence: verified · Build: steam-5d11de53 · Fact ID: decal-undrawn-in-game

The 1-second undrawn deletion is real: novae (ajane) saw decals vanish when they looked away. Raising the time the four comparisons use stopped it, and decals then lasted minutes (10,000 survived a whole mission).

Basis: novae (ajane)'s screenshots and play-testing (v02+); novae (ajane); decals lasted minutes from v02 on

Attribution: novae (ajane), PROJECT_SUMMARY section 2, lessons · 2026-10-12

Eviction 1A0860 (called with the new decal) walks the manager's list (+0xE8, count +0xF0), considering decals…

Evidence: static · Build: steam-5d11de53 · Fact ID: decal-eviction

Eviction 1A0860 (called with the new decal) walks the manager's list (+0xE8, count +0xF0), considering decals that are alive and not fading. Rank = (1 - age/lifetime) * strength(+0x14C) * (1 - undrawn(+0x13C)) (lifetime <= 0 -> huge). It tracks the lowest rank overall and the lowest among decals whose bounds overlap the new one, plus the overlap count. Then: count > 100 (cmp qword [r13+0xF0],0x64 at 1A0999) -> remove the lowest overall; overlap >= 6 (1A09DE) -> set that one's lifetime to 0 (it fades); overlap > 8 -> remove it at once (1A25A0). All decal kinds share this one pool.

Basis: disassembly and emulator

Addresses (build-specific RVAs unless indicated): 1A0860, 1A0999, 1A09DE, 1A25A0

Attribution: novae (ajane), internals section 10 · 2026-10-12

The manager's pool is a std::list: sentinel pointer at +0xE8, count at +0xF0, node {next, prev, decal} (decal…

Evidence: static · Build: steam-5d11de53 · Fact ID: decal-manager-list

The manager's pool is a std::list: sentinel pointer at +0xE8, count at +0xF0, node {next, prev, decal*} (decal at +0x10). 1A0860 appends new decals at the tail (1A0A14..1A0A74), so [sentinel] is the oldest. The manager lives in a static pair {manager*, control block*} at 0x1259C80 (use count at ctrl+8); the getter 1A1EE0 creates a manager when the pair is empty, so read the pair instead of calling it.

Basis: disassembly and emulator (v08 clear key)

Addresses (build-specific RVAs unless indicated): 1A0860, 1A0A14, 1A0A74, 1259C80, 1A1EE0

Attribution: novae (ajane), internals "Added in the v08 round" (1) · 2026-10-12

Removal calls: 617B30(object) is the object-level kill (skips if +0x30 & 4, runs virtual +0x28, sets that bit…

Evidence: static · Build: steam-5d11de53 · Fact ID: decal-removal-calls

Removal calls: 617B30(object) is the object-level kill (skips if +0x30 & 4, runs virtual +0x28, sets that bit, unregisters from the scene registry); every decal update calls it when a decal's life ends, and it is safe to call twice. 1A25A0(decal) only erases the decal's node from the manager list. Soft removal: virtual +0x50 (every decal type uses the default 1A2590: lifetime := 0) starts the fade.

Basis: disassembly and emulator

Addresses (build-specific RVAs unless indicated): 617B30, 1A25A0, 1A2590

Attribution: novae (ajane), internals "Added in the v08 round" (2), (3) · 2026-10-12

Spawners, reach and size

Spawners: 1AF660 hit blood (checks the spawn point is on screen via 614CE0, distance = 600 x scale, then call…

Evidence: static · Build: steam-5d11de53 · Fact ID: decal-spawners

Spawners: 1AF660 hit blood (checks the spawn point is on screen via 614CE0, distance <= 600 x scale, then calls 1AFAF0; callers are enemy classes); 1AFAF0 builds the SplashProjection (casts a ray of length far = min(per-enemy limit, 40..60 x scale) and only makes the decal if it hits; fov 45 degrees; the volume is a perspective frustum, so "size" = cone width); 23F810 HumanoidPartsBreakEffect_Blood; 1B6210 death pool (strength = 2 x size arg, size = 9.75 x scale); 1B5850 ant acid splash (AcidBullet01 ticks 137060; lifetime 20, strength 3 x size); 1B03B0 bullet mark; 1B0AF0 explosion mark; debug console commands 67440/67820/689C0. Per-enemy blood parameters are game data (ant_BloodScale, dragon_BloodColor, ...). Textures: BloodSplash_01/02, ExplosionMark_Add/Color/Height/n.

Basis: disassembly

Addresses (build-specific RVAs unless indicated): 1AF660, 614CE0, 1AFAF0, 23F810, 1B6210, 1B5850, 137060, 1B03B0, 1B0AF0, 67440, 67820, 689C0

Attribution: novae (ajane), internals section 10 · 2026-10-12

The blood spray's far (1AFAF0) is loaded once into xmm9 (1AFB46) and used three ways: copied to xmm7 at 1AFB5…

Evidence: static · Build: steam-5d11de53 · Fact ID: blood-spray-far

The blood spray's far (1AFAF0) is loaded once into xmm9 (1AFB46) and used three ways: copied to xmm7 at 1AFB57 as the ray length (the gate: no hit, no decal); stored at 1AFD57 as the far plane of the projected volume; divided by 40 (1AFBAD) for the decal's rank (+0x5C in the init struct) and, doubled, the distance the projector is pulled back along its axis (1AFF43..1AFF84: apex = impact point - axis x far/20). A cone widens with distance from its apex, so scaling far at the load makes every splat wider at a given wall; hook the ray (1AFB4F..) and the far plane (1AFD57) separately.

Basis: disassembly (v07 round)

Addresses (build-specific RVAs unless indicated): 1AFAF0, 1AFB46, 1AFB57, 1AFD57, 1AFBAD, 1AFF43, 1AFF84, 1AFB4F

Attribution: novae (ajane), internals "Added in the v07 round" (1) · 2026-10-12

Size: the Decal_Splash constructor reads its size at +0x340

Evidence: static · Build: steam-5d11de53 · Fact ID: decal-size

Size: the Decal_Splash constructor reads its size at +0x340; a projected decal's width is set by the projection matrix terms m00 and m11 (dividing them by a factor widens the volume; depth is unchanged). A spray paints wall and floor in one volume, so a per-surface size per decal is impossible (pools are the ground-only type).

Basis: disassembly; novae (ajane)

Smoulder (impact glow)

The draw-prep virtuals of Decal_BulletMark (19D8F0) and Decal_ExplosionMarks (19EDC0) blend two shader color…

Evidence: static · Build: steam-5d11de53 · Fact ID: decal-smoulder

The draw-prep virtuals of Decal_BulletMark (19D8F0) and Decal_ExplosionMarks (19EDC0) blend two shader color sets (+0x350.. and +0x360.., written to +0x1E0..) by w = 1 - (age/(D+1))^2. D is at +0x34C for bullet marks (the spawner sets clamp(size*0.15, 0.4, 1.2), so the glow lasts 1.4-2.2 s) and at +0x344 for explosion marks (min(lifetime*0.25, 10), about 6 s). It is a heat/glow animation, not a particle effect; rising smoke wisps are particles and separate.

Basis: disassembly (v06/v07 rounds)

Addresses (build-specific RVAs unless indicated): 19D8F0, 19EDC0

Attribution: novae (ajane), internals "Added in the v06 round" (2), "v07 round" (2) · 2026-10-12

What decals are not; leads

Decals are world-space volumes registered as scene nodes (617010)

Evidence: static · Build: steam-5d11de53 · Fact ID: decal-world-space

Decals are world-space volumes registered as scene nodes (617010); nothing ties a decal to the object it landed on (the raycast hit object in 1AFAF0 only gates creation). [0x125AB68] is a global with about 530 users (a world/scene object), not the decal manager.

Basis: disassembly

Addresses (build-specific RVAs unless indicated): 617010, 1AFAF0, 125AB68

Hook-site coexistence

The local-player update (0x3094D6..) has separate instruction sites, so several patches can each rewrite a di…

Evidence: static · Build: steam-5d11de53 · Fact ID: player-update-hook-sites

The local-player update (0x3094D6..) has separate instruction sites, so several patches can each rewrite a different one and all load: 0x3094D6 (cmp qword [rdi+0x240],0, non-relative, 8 bytes, its flags feed the game's je), 0x3094EC and 0x30952D.
