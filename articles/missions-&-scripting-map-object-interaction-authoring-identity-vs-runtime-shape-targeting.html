Evidence: static inspection of shipping EDF6 MISSION.AC call sites and their paired mission RMPA shape names. The counts below are corpus counts, not independent runtime tests.

Examples include MapObjectDestroy4("破壊01") and MapObjectInvincible("倒壊ビル00_1"). The string argument resolves to a mission RMPA shape name, not to an established persistent binary map-object handle or placement identifier.

Spatial selection versus object identity

A named mission RMPA shape defines a spatial target. It may cover more than one map-owned prop, so MapObject* calls cannot be assumed to affect exactly one uniquely identified MAPB/MAPO object. Maps, mission scripts and their spatial selection resources remain distinct file families.

Do not replace a source-observed name/shape lookup with a guessed runtime instance_id or authoring project identifier. The corpus does not prove such a game API exists. MapObjectDestroy4_Group is observed, but a universal grouping/selection law was not recovered by this bounded study.
