Format-by-format conversion rules and exceptions

Source-backed research / case study · Reconciled

Evidence level: Reconciled assertion ledger plus later domain-specific research. The ledger is a provenance/search layer, not a flat truth table.

Observed ledger state: R6_UNIFIED_KNOWLEDGE_ASSERTION_LEDGER.json contains 48,938 deduplicated assertions from 61,542 raw records. It intentionally preserves reference, historical, negative and superseded statements alongside current rules. Only claims with an appropriate current evidence status are promoted below.

Implementation rule: Never count a preserved assertion as current merely because it is present in the ledger. PRESERVED_REFERENCE, PRESERVED_POST_EVIDENCE, historical and open statuses remain evidence/provenance until a current domain authority promotes them.

The following includes current, conditional, profile-specific and explicitly superseded rules. Superseded entries are deliberately retained so old handoffs can be interpreted correctly.

BVD

  • BVD_32_CURRENT — CURRENT_RULE — Current compound BVD slice measurement is 32 B at +0x5C.
  • BVD_36_OLD — SUPERSEDED — Older 36-byte BVD slice is superseded by measured 32-byte slice.
  • BVD_SOLE_ROOT_CAUSE_OLD — SUPERSEDED_CAUSAL_CLAIM — BVD correctness matters structurally but BVD-only fixes did not recover floor collision.

BVM

  • BVM_CREATE_DISPATCH_CURRENT — CURRENT_RULE — Use the corrected AC/6C dispatch examples; 6C D0/6C F2 are not CreateEnemy/CreateFriend.
  • BVM_CUSCALL_2000_ENCODING — CURRENT_RULE — AC is the BVM cuscall0 opcode and D0 07 is the little-endian integer 2000; decimal custom-call IDs were not hallucinated.
  • MISSION_INVALID_OPCODE_RANGE — CURRENT_RULE — Retained invalid/crashing BVM opcode range is 0x39-0x3F; older 0x3A-0x3F range was incomplete.

CANM

  • CANM_VERSION_ONLY_UNSAFE — CURRENT_RULE — CANM requires structural/channel semantic conversion, not a version bump.

CAS

  • CAS_UNKNOWN — UNRESOLVED — CAS remains incompletely understood; do not infer universal passthrough.

CMPL

  • CMPL_TOKEN_CURRENT — CURRENT_RULE — Current CMPL token decode formula.
  • CMPL_TOKEN_OLD — SUPERSEDED — Old high-nibble-length CMPL formula is wrong; use len=(tok&0xF)+3, pos=tok>>4.

CPK

  • CPK_UNPACKED_DIR — CURRENT_RULE — *.cpk_unpacked is a source directory in this workflow; raw CPK parsing is peripheral.

DSGO

  • DSGO_LIST — CURRENT_RULE — EDF6 mission LIST resources use DSGO; lossless round-trip uses block pipeline.

FMB

  • FMB_ASIS_SCOPE — PROFILE_SPECIFIC_NOT_UNIVERSAL — EDF5 FMB passthrough is observed for particular shared/render-side cases; it is not a universal source-only FMB container rule.
  • FMB_PHYSICS_CAUSAL_OLD — SUPERSEDED_CAUSAL_CLAIM — FMB terrain render/spatial data is established; FMB alone is not established as universal floor-physics source.
  • FMB_PLUS5_UNIVERSAL_OLD — SUPERSEDED_AS_UNIVERSAL — No universal +5 rule; 0x58/chunk index mapping is map/content specific.
  • FMB_VALUE5_CANDIDATE — CANDIDATE_SPECIFIC_CURRENT — Value 5 is recorded for the 2026-08-21 Desert clean candidate; it is not a universal format law.
  • R6_NO_FMB_IG — CURRENT_CORRECTION — IG_EDFROOM01/02 do not have FMB; do not request it for exact-pair RoomB research.

MAB

  • MAB_UNKNOWN — HISTORICALLY UNRESOLVED / NOW PARTLY SUPERSEDED — The R6 ledger predates later bounded MAB research. For validated MAB\0 v15, EDF4.1/EDF5 internal offsets use flag 0x03 and EDF6 uses struct-relative flag 0x83, with a measured 1,318-pair comparison. This is a known pointer-encoding migration, not a universal model/weapon retargeting law. See MAB source-backed binary contract.

MAC

  • MAC_OUTPUT_CLEAN_PROVENANCE — PROVENANCE_QUALIFIED — Clean MAC output can still be reference-assisted through Base502-derived SGO templates; output cleanliness is not source-only provenance.

MAD

  • MAD_BITFIELD_HKUINT32 — CURRENT_RULE — Canonical tested serializer emits the bitfield array item as hkUint32.
  • MAD_CONVEX_RADIUS — CONDITIONAL — Native/candidate evidence contains both 0.00 and 0.01; choose by shape/profile, not globally.
  • MAD_DESCRIPTOR_FLAGS_CURRENT — CURRENT_RULE — hknpMaterialDescriptor flags are uint32 0x0000ffff in the corrected serializer; 0xffff0000 was a serialization mistake.
  • MAD_DISPATCH14_LABEL_CONFLICT — CONDITIONAL — Late notes use the label dispatchType for value 14 at +0x04; earlier detailed layouts put dispatchType=3 at +0x01. Do not overwrite +0x01 solely from this label; distinguish byte offset from semantic field name.
  • MAD_DISPATCH_BYTE1_3 — CURRENT_RULE — Detailed 52-byte hknpCompressedMeshShape layouts identify +0x01 dispatchType=3.
  • MAD_MOTION104_CURRENT — CURRENT_RULE — Havok 2020 hknpMotionProperties is a 104-byte record; never copy EDF5 hkpMotion bytes into it.
  • MAD_NAMEDVARIANT65_PROFILE — PROFILE_SPECIFIC_NOT_UNIVERSAL — 65 NamedVariants belong to the historical Base502 carrier profile; root/name lookup is important but count 65 is not universal.
  • MAD_OFFSET4_14_LATE — CURRENT_RULE — Late crash-forensics measures +0x04=14 for the tested compressed-mesh carrier family. It called this dispatchType, but earlier member-layout evidence calls +0x04 numShapeKeyBits; preserve the byte rule while treating the member-name conflict as unresolved.
  • MAD_OUTPUT_CLEAN_PROVENANCE — PROVENANCE_QUALIFIED — Output-clean/zero-graft is not equivalent to build-time SOURCE_ONLY while EDF6 registry/template metadata is imported.
  • MAD_PRIMITIVE_KEYS_CURRENT — CURRENT_RULE — Primitive records with c==d contribute one key/triangle; c!=d contributes two keys/triangles.
  • MAD_PROFILE128_UNIVERSAL_OLD — SUPERSEDED_AS_UNIVERSAL — 128 is a tested profile, not a universal native limit.
  • MAD_SDK_STRING_ONLY_OLD — SUPERSEDED_OR_PARTIAL — SDK string patching alone is not hkp2015->hknp2020 conversion.
  • MAD_SHAPE_TYPE_IDS — CURRENT_RULE — Corrected EDF6 hknp shape-type IDs: convex 0, cylinder 3, box 5, mesh/compressed mesh 8, compound 11.
  • R6_DESERT_R10C — CURRENT_RUNTIME_CONFIRMED — Accepted source-only Desert MAD/R10C baseline: 86,835,336 bytes, SHA eb1f...; clean source+reconstructed-schema rebuild reproduces it byte-for-byte and runtime is accepted.
  • R6_MAD_FPI_GATES — CURRENT_RULE — Accepted Desert MAD gates: 11,873/11,873 FPI sections; 1,100,848 unique primitive keys reachable exactly once; 0 missing/extra/duplicate/AABB violations; 181 bodies, 370 terrain meshes, 2,045,747 terrain triangles, 16,132 direct-mesh triangles.
  • R6_MAD_TOPOLOGY_POLICY — CURRENT_RULE — Runtime-safe Desert compressed-mesh policy: baseline split topology is preserved; flat→split only when final quantized geometry disqualifies flat; never synthesize split→flat in compatibility mode; production triangleIsInterior is zero.
  • R6_OLD_262M — HISTORICAL_RUNTIME_CONTROL — The older 262 MB Desert deployment is historical runtime-control evidence, not current architecture or source-only proof.
  • R6_OLD_CLEAN_SUITE — SUPERSEDED_OR_PROVENANCE_QUALIFIED — The Aug-21 ~85 MB clean-suite candidate is historical/reference-assisted provenance and is superseded by the later runtime-accepted source-only R10C baseline.

MAE

  • MAE_NO_EDF5 — CURRENT_RULE — MAE is EDF6-side synthesis/reference-assisted construction because EDF5 has no direct MAE.

MAPB

  • MAPB_INSERT_0X20_CURRENT — CURRENT_RULE — EDF6 T1 adds zero dword at +0x20; old +0x20 moves to +0x24.
  • MAPB_INSERT_0X24_OLD — SUPERSEDED — Old T1 insertion-at-+0x24 claim is superseded.

MAPO

  • MAPO_AUX_FLOOR_CAUSAL_OLD — SUPERSEDED_CAUSAL_CLAIM — MAPO layout/registration is important, but auxiliary-table validity alone is not a floor-collision solution.
  • MAPO_STRIDE1C_CURRENT — CURRENT_RULE — MAPO +0x08 object-table element stride is 0x1C/28 B in the reconciled runtime-resource audit.
  • MAPO_STRIDE8_OLD — SUPERSEDED — MAPO +0x08 object-table 8-byte stride interpretation is superseded by 0x1C/28 B.

MAP_RESOURCE_REFS

  • MAP_RESOURCE_TRB_CAPACITY — CANDIDATE_SPECIFIC_CURRENT — Latest clean Desert handoff reports a per-resource T2/TRB capacity mismatch (218 instances vs 2 transforms); this is not a suffix conversion law.
  • MAP_RESOURCE_TRB_RENAME_OLD — SUPERSEDED_AS_UNIVERSAL — Do not globally rename .trb to .mdx; the historical crash attribution was later entangled/superseded by the corrected CMPL decoder.

MARC

  • MARC_U1_DELTA — CURRENT_RULE — Shared MARC grammar; measured map-entry u1 differs EDF5=2 vs EDF6=0.

MDB

  • MDB_FMT1_16_CURRENT — CURRENT_RULE — MDB format/type 1 = 16 B float32[4].
  • MDB_FMT1_4_OLD — SUPERSEDED — MDB format/type 1 = 4 B is superseded; current width is 16 B float32[4].
  • MDB_VERSION_ONLY_OLD — SUPERSEDED_OR_PARTIAL — Version/header gate patch is a loader experiment only, not native parity.

MISSION_AC

  • MISSION_ISVALIDITY_BAN_OLD — SUPERSEDED — Blanket .IsValidity() bans are superseded by retained human/in-game evidence.
  • MISSION_MOVE_SPEED_CURRENT — CURRENT_RULE — Use SetAiMoveSpeed for the reconciled speed-call case; older SetAiRouteSpeed mapping is stale there.
  • MISSION_RADIO_HELPERS — CURRENT_RULE — RadioBegin/RadioEnd are defined in ASCOMMON.H in the retained reference; do not model them as built-ins solely from native call style.
  • MISSION_RANDOM_TALK_CURRENT — CURRENT_RULE — 4004/4005 map to EnableAiRandomTalk/DisableAiRandomTalk respectively.
  • MISSION_RELEASE_READY_OLD — SUPERSEDED_OR_OVERCLAIM — Syntax/build success does not establish semantic/runtime parity.
  • MISSION_ROUTE_OMIT_OLD — SUPERSEDED — Blanket route omission is superseded; preserve route behavior and convert the relevant calls.
  • MISSION_ROUTE_SPEED_OLD — SUPERSEDED — SetAiRouteSpeed is superseded for the reconciled 3100 case by SetAiMoveSpeed.
  • MISSION_TIMING_SCALE_OLD — SUPERSEDED — Global 1.5x timing scaling is superseded; preserve ASM timing values unless a call-specific rule is proven.
  • R6_2006_2008 — CURRENT_EXACT_PAIR_CONFIRMED — 2006 and 2008 are opcode-defined lowerings: 2006→CreateFlyingEnemyGroup_Area; 2008→CreateEnemyGroup_Area. Do not choose via SGO flying/ground heuristics.
  • R6_2009 — CURRENT_EXACT_PAIR_CONFIRMED — 2009 maps to dedicated CreateEnemyGroup_Area_Spawn; old nested .Spawn construction is superseded.
  • R6_3023 — CURRENT_EXACT_PAIR_CONFIRMED — 3023(1) lowers to SendTeamEncount(TEAM_ID_ENEMY); historical 1.Delete() artifact is wrong.
  • R6_3100_3102 — CURRENT_EXACT_PAIR_CONFIRMED — 3100→global SetAiMoveSpeed, 3101→SetAiRoute, 3102→SetAiPath; route/path must not be merged.
  • R6_3450 — ACCEPTED_FIDELITY_WAIVER, NOT A CURRENT PORT/WIKI BLOCKER — SetAiSearchRadius(Object,float) writes EDF5 object+0x2E0 / EDF6 object+0x470; all six shipping occurrences are in DM006_2. The direct AngelScript binding is not proven. The deliberately omitted 3450-OFF runtime candidate spawned frogs and completed the mission; document the loss of source-specific search radii rather than mislabeling it a current blocker. Strict exact-parity conversion can still fail closed; never substitute 3024/3150.
  • R6_API_SEQ — CURRENT_GATE_CONFIRMED — R37 semantic gates: 1560/1560 anchored API name/sequence parity; 8088 direct calls with only nonblocking M001 alias residual; 58/58 compound semantic tokens.
  • R6_CREATEENEMY2 — CURRENT_RUNTIME_CONFIRMED — Source opcode 2001 maps to CreateEnemy2; runtime-confirmed for DM019 wall anthill/spawner orientation. Do not merge with 2000 CreateEnemy.
  • R6_DM019_FRIENDS — CURRENT_SOURCE_SEMANTICS — DM019 creates three recruitable friend squads and immediately assigns routes/speeds; idle-until-recruited behavior is inconsistent with source intent.
  • R6_DM019_GOLDANT — CURRENT_SOURCE_SEMANTICS — DM019 source semantics: enemy02 has ordinary GiantAnt04×3 below higher-difficulty branch and GoldAnt×3 in higher branch; enemy03 unconditionally creates GiantAnt04×70, GiantAnt04sb×30, GoldAnt×5 in that order.
  • R6_DM019_LIGHT — CURRENT_RUNTIME_CONFIRMED — DM019 lighting omission was a mission transpiler bug; restoring source lighting calls fixed runtime lighting.
  • R6_DM020_TANKS — CURRENT_SOURCE_SEMANTICS — DM020 source constructs tank01_1..4 only; tank01_5/6 are read later without source constructors. Do not synthesize them; solve declaration/type inference.
  • R6_EVENT_SENTINEL — CURRENT_EXACT_PAIR_CONFIRMED — Exact44 end-event sentinel: source end registration delay 100.0 maps narrowly to EDF6 target 100000000.00; this is not blanket time scaling.
  • R6_EVENT_SLOTS — CURRENT_EXACT_PAIR_CONFIRMED — One target event state per unique reachable source target: exact44 has 2214 registrations and 2106 unique targets; official MAX_EVENT_ID sum is 2106. IDs use first-registration order, not Func_N numbers.
  • R6_FACTOR_9201_9202 — CURRENT_EXACT_PAIR_CONFIRMED — 9201=Factor_ObjectDestroy and 9202=Factor_ObjectEncount; old merged interpretation is wrong.
  • R6_FIFO — CURRENT_RULE — Contiguous source side effects must emit in source execution order/FIFO; old LIFO pending-expression behavior was a corpus-wide semantic bug.
  • R6_GLOBAL_RW — CURRENT_GATE_CONFIRMED — R37 global dataflow gate: exact44 4618 reads/2106 writes/0 missing; shipping141 9898 reads/4864 writes/0 missing.
  • R6_GROUP3500 — CURRENT_EXACT_PAIR_CONFIRMED — ObjectGroup family is exact-pair confirmed: 3500 AddGroupObjectBegin, 3501 AddGroupObjectEnd with no fake pop, 3502 GetGroupObjectCount expression.
  • R6_M001_ALIAS — OPEN_NONBLOCKING — M001 ap111 vs official npc_ap025_surprise remains a nonblocking target-compatibility/alias question; preserve source unless runtime/resource evidence proves a narrow alias.
  • R6_M041 — CURRENT_EXACT_PAIR_CONFIRMED — M041 pre-registration 9000 is a narrow compiler idiom lowered as in-body Wait, not child factor; the old R20 event-order warning is resolved.
  • R6_M098_REFERENCE — CURRENT_CORRECTION — Historically named M098/OFFICIAL.AC is reference/reconstructed material, not one of the 44 exact official pairs; source BVM wins for recoverable counts/timing/booleans.
  • R6_MULTI_EVENTTYPE — CURRENT_BINARY_CONFIRMED — Binary-confirmed source-faithful mapping: BVM multi==1 → EVENT_TYPE_ASYNC; otherwise EVENT_TYPE_SYNC. EDF5/EDF6 BVM and EDF6 AngelScript scheduling policies are semantically isomorphic.
  • R6_MULTI_NEQ_OLD — SUPERSEDED — Old multi!=0 lowering is superseded; runtime checks equality to 1.
  • R6_NO_SHELL_INJECTION — CURRENT_RULE — Do not inject SetFullLightWeightMode or ragdoll settings unconditionally; emit source semantics only.
  • R6_NO_TIME_SCALE — CURRENT_RULE — Preserve source timing; no blanket ×1.5 conversion.
  • R6_PROVENANCE_COMMENTS — CURRENT_RULE — Keep machine-readable EDF5_CUSCALL provenance comments for nontrivial/direct lowerings so direct and compound target API emissions can be distinguished.
  • R6_R20_LATEST — SUPERSEDED — R20/R30 are historical research checkpoints. Continue mission work from R37, not R20/R30.
  • R6_R20_OPEN_CFG — SUPERSEDED — R20 six backward CFG cases and M041 warning are resolved in R37; do not reopen from R20 handoff.
  • R6_R37_STATUS — CURRENT_RESEARCH_STATE — R37 is the latest mission research candidate and supersedes R20/R30 as research continuation point, but remains blocked from canonical promotion.
  • R6_REACHABLE_EVENTS — CURRENT_EXACT_PAIR_CONFIRMED — Exact44: 2233 raw RegisterEvent calls reduce to 2214 reachable registrations, matching 2214 official internal_CreateEvent calls. Dead compiler Func_N branches must be excluded by source reachability.

  • R6_SWITCHES — CURRENT_GATE_CONFIRMED — R37 control-flow gate is green for shipping141; the six old R20 backward-layout cases are recognized as switches and there are zero fallbacks/warnings/leaked CFG markers.

NAVMESH_HKT

  • NAV_HKT_GENERATION — CURRENT_RULE — Navmesh HKT requires Havok 2015/64-bit -> 2020/32-bit re-encoding.
  • R6_CLEARANCE — DEPRIORITIZED — Clearance ABI/seeding mismatch is strongly deprioritized by exact-pair/version-contract evidence.
  • R6_DEEP_CONVEX — CURRENT_STRUCTURAL_FINDING — A real high-only source streaming bridge penetrates a closed RoomB convex collider (~1.1083 m, fraction ~0.9947); generic detector reproduces R2O, but runtime-negative result prevents treating it as behavioral root cause.
  • R6_DEEP_THRESH — CURRENT_RESEARCH_RULE — Current deep-convex source-consistency detector uses closed convex primitives, ≥0.05 m solid penetration and ≥0.90 fraction; it is a research sanitizer candidate, not a universal native exporter rule.
  • R6_FILTER_CLOSED — FALSIFIED_OR_CLOSED — RoomB collision filter/query-mask hypothesis is closed; source/native metadata do not expose a missing mask explaining NPC-only behavior.
  • R6_GRAPH_DECODER — CURRENT_CORRECTION — Historical graph decoder read narrow ints/hkHalf16 incorrectly; canonical graph decoders were fixed. Serializer output was unaffected because raw ITEM data was preserved.
  • R6_INVERSE_BAKE — CURRENT_RULE — Exact native HKT parity is an inverse-bake/rebake problem, not a simple version patch: native EDF6 often changes topology and runtime HKT does not serialize every generation setting.
  • R6_PHYSICAL_WALL — CURRENT_RUNTIME_CONFIRMED — Physical wall collision exists; web projectiles stop at the wall and actors cannot cross. The remaining symptom is primarily AI-vs-AI targeting/perception/query semantics.
  • R6_R2O_NEGATIVE — CURRENT_RUNTIME_NEGATIVE — R2O high-only removal of the deep-convex streaming stitch is runtime-negative for the AI wall symptom. The stitch remains a structural consistency finding but is not sufficient behavioral root cause.
  • R6_STATIC_TREE — DEPRIORITIZED — DM019 static-tree defect is strongly deprioritized after all 10 low + 10 high tiles passed reachability/permutation/AABB/domain checks.
