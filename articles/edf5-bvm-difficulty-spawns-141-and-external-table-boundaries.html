EDF5 141-script difficulty survey: spawn variants, loop paths, and enemy counts versus game tables

EDF 5Game technical referencesMissions / source-vs-game interpretation
Technical reference · Source static analysis; explicitly identified source hypotheses retained

The retained original EDF5 source analysis covers 141 shipping BVM scripts. Custom call 21 queries difficulty in the observed source set: its numeric cases represent Easy through Inferno (0–4). A mission may branch on this value and modify spawn counts, HP factors, generator parameters or event timing. Across the source survey, 92/141 missions change enemy lists or counts by difficulty. The study records that 111/141 call 21; other scripts can still vary by external game difficulty logic.

A source walkthrough must preserve branches, repeated event handlers and loops. For example, an EDF5 switch can place case bodies before a backward dispatch ladder: a reader that follows the physical instruction order can accidentally run the last difficulty case for every mission. In M059 the correct sampled Blue Tadpole count across difficulties is 2 / 4 / 6 / 8, not 8 at every difficulty.

The script totals were compared with historical Japanese wiki tables (not all tables were expressed in the same way). Exact totals across difficulties were found in 23 missions, with another 21 matching only at Inferno. Remaining differences are not automatically errors in the BVM interpreter. Generators can spawn repeated waves; a wiki may show an infinity marker, an interval or the highest difficulty's population, rather than a raw sequential script count.

Concrete examples show different interpretations:

  • M021 / offline 31: source script spawns 240 enemies in its audited path; the wiki reports 335 because it counts the Outpost itself and 94 turrets inside the SGO (240 + 1 + 94 = 335).
  • M000 / offline 1: script and wiki totals differ because one ant is created as an event object and two target-group handlers exist; the summary lists only one of the two groups.
  • M004: the source survey gives 153/155 Teleport Anchors on examined paths; the source author explicitly marked the 28-anchor repeat hypothesis unverified. Do not relabel its runtime explanation as proven.
  • M008: a carrier wait loop can remain active until external event state changes; simply stopping at a repeated branch undercounts later enemies.

The observations establish the importance of mission execution context. They do not establish an exact final number of enemies killed in a live game session, which also depends on death, generator ownership and player actions.

Evidence: bvm-getdifficulty-21, bvm-per-difficulty-eval, bvm-eval-loop-exit-fix, bvm-switch-form, bvm-wiki-gaps-explained (static), m004-anchor-event-twice (unverified).

Two exact mission-table cross-checks

These examples compare specific source script states with external Japanese mission tables, not generic difficulty scaling claims:

  • M046_3 (offline 70 / online 69): eight waiting Imperial Drones consist of one 2006 area group of five plus three 2001 CreateEnemy2 calls, all inactive at spawn and scalar 1.0. The cited sergeant's factor 1.5 is a 1010 friendly leader, and the railgun factor 2.0 comes from 1029. A later fourth drone switches to attack mode via 3022. This BVM has no 21 GetDifficulty, so its authored enemy list is fixed across difficulties in the inspected script.
  • M081 (Scorched Earth; offline 108 / online 107): verified static table-vs-BVM HP factors include Deroy 0.65, spiders 0.8, Type-2 drones 0.7, greys 0.8, Queen Bee 0.7 and Imperial Drones 0.7. The extra-large Teleport Anchor is 0.36 at Hard and below, 0.48 at Hardest/Inferno. Four large Anchors use 0.6 / 0.8 by difficulty; the mission-wide call-20 factor is 1 / 1 / 0.9 / 0.9 / 0.8. These are two distinct multiplier layers, not a combined final native HP value.

Evidence: native source / external table static comparison for atwiki-matches-script-m046-3 and atwiki-matches-script-m081 in edf5/mission-vm.md, build steam-5d11de53. The game was not replayed for these checks.
