Crosswalk: armor gauge, aim line, FOV, mission clear marks (key: HUiHudPowerGuage) — community crosswalk

Technical reference · Community crosswalk, source-reported classifications

Armor gauge text cap (key: RTTI HUiHudPowerGuage)

  • edf41: cap 999999 in the gauge update, one mov eax,999999 for cur and max | ref: edf41/hud.md#armor-gauge-cap | evidence: static
  • edf6: the same cap, one mov eax for cur, max and two stored copies | ref: edf6/hud.md#armor-gauge-cap | evidence: static
  • edf5: the same cap and the same stored copies [rbx+0xAE0] / [rbx+0xAE4] as EDF6 | ref: edf5/hud.md#armor-gauge-cap | evidence: static
  • Differences noticed: identical byte sequence B8 3F 42 0F 00 3B D0 in every game (FevGrave), different addresses.

Vehicle weapon aim line during cooldown

  • edf41: cooldown test [rbx+0xAB0] > 0; color floats at +0x104.. | ref: edf41/hud.md#aim-line-cooldown | evidence: static
  • edf6: cooldown test against [rbx+0xE0C]; color floats at +0x114.. | ref: edf6/hud.md#aim-line-cooldown | evidence: static
  • Differences noticed: same idea (metoxys's WeaponAimLineContextual), different gate and field layout.

Vertical FOV constant

  • edf41: pi/4 constant divided by [+0x310], stored to the camera's +0x14 | ref: edf41/rendering.md#vertical-fov | evidence: static
  • edf6: pi/4 constant divided by [+0x410], stored to the camera's +0x24 | ref: edf6/rendering.md#vertical-fov | evidence: static
  • Differences noticed: EDF6's +0x24 matches the projection fields recorded for CharacterGhostCamera (edf6/camera.md#ghost-camera-get-projection); EDF 4.1's camera object is not named.

Mission clear marks (save data)

  • edf41: one bit per difficulty in [save + 0xEE8 + class*0x200 + mission]; only the cleared difficulty is marked | ref: edf41/missions.md#mission-clear-bits | evidence: static (FevGrave reports the patch tested)
  • edf5: same bits in [save + 0x566C + class*0x200 + mission]; Normal and Hard also mark the lower ones | ref: edf5/mission-flow.md#mission-clear-bits | evidence: static (FevGrave reports the patch tested)
  • edf6: same bits in [save + 0x57AC + class*0x200 + mission]; same rule as EDF5 | ref: edf6/missions.md#mission-clear-bits, #mission-clear-cascade-v2 | evidence: static
  • Differences noticed: same bit values and 0x200 bytes per class; different base offset and cascade.
  • Confidence in the mapping: high for the armor cap (identical code), medium for the rest.
  • Added: 2026-10-16 src: FevGrave, metoxys, BlueAmulet (novae (ajane)'s outside sets)
