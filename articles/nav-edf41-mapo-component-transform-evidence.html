EDF 4.1 MAPO: quaternion, translation and tint vector evidence

EDF 4.1Maps & NavigationMaps
Technical reference · Native source-corpus and exact oracle, offline reconstruction only; no EDF6 in-game runtime tests

Scope: selected source MAPO rows involved in R1D navigation reconstruction. Evidence class: native source-data enumeration plus offline conversion experiments. This is not a universal format schema for every EDF map.

The three vector lanes

The selected MAPO rows expose several vector-like fields. Their observed interpretations and confidence levels are different:

Source field Current evidence What not to infer
vec08 Rotational component: 3,415 non-null selected rows; 3,415/3,415 unit-length within 1e-5, with pure Y-axis xyzw quaternion form It is not an independent rigid-body selector
vec0c Component-relative position, varying within 1,675 repeated (placement,group) instances A repeated instance must not be silently collapsed to its first slot
vec10 RGB/tint-like values: 11,918 non-null rows, fourth component always zero, RGB values within [0,1], none unit-length within 1e-5 It is not established as a collision transform

The vec08 quaternion rotations, after q/-q normalization, form four observed values in the 3,415 non-null sample:

Y-axis rotation Rows
Identity 1,327
+90 degrees 1,046
180 degrees 693
−90 degrees 349

The total is 3,415. 610 repeated (placement,group) instances vary in vec08. In a 1,675-instance repeated-row analysis, all 1,675 vary in vec0c, and 667 instances also vary in non-position vectors. Of those 667, 114 had exact-zero MAPB placement rotation. These distinctions matter: MAPB placement rotation and MAPO component rotation are separate fields.

Component transform versus rigid-body identity

Matching a component quaternion/translation to an arbitrary MAD rigid body is not justified by the source evidence. In the selected corpus:

  • 479 active R32 rigid bodies contain zero non-identity motionState rotations.
  • In the larger set of all selected-group bodies, 17 have non-identity body-motion rotations.
  • Among 11,988 selected referenced MAPO slot/group pairs, 215 component-position vs body-motion-translation pairs match within 1e-5.
  • Only 5 match the full transform under the additional identity-quaternion requirement, all trivial zero-transform cases.

Implementation rule: treat vec08 + vec0c as a candidate component/group-instance transform. Do not resolve a specific source collision body solely because it shares a MAPO leaf name or approximate translation. Neither matching a class name nor duplicating a body pointer establishes ownership.

Negative carve result

Eight natural post-activation carving variants were constructed using global first/last source-row representatives for each (T2,group) and four natural group orderings. Every variant preserved the frozen R32 4,994 pre-dedupe / 23 removed / 4,971 final population.

The complete retained finite carve-family enumeration over all eight geometries yielded zero natural 277-face sets. Thus this specific full-component-transform carve construction does not recover historical R1D geometry. It says nothing conclusive about the independent use of these vectors in rendering, authored placement, other map families or alternate native collision paths.
