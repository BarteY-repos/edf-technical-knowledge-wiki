This is a source-attributed research appendix, not a chronology or a replacement for topic reference pages. The observations were contributed in the EDF Knowledge Hub export, snapshot 2026-11-14, revision 54f89cd, compiled by novae (ajane).

Read each statement with its evidence grade and exact build. Verified means a reported game test, static means reverse engineering or source inspection without a reported game test, and unverified is a hypothesis. None of these observations was newly tested for this wiki release.

Reader-oriented synthesis

For grouped explanations and comparable formula tables, use insects and tadpoles, drones and Deroys, MonsterBase/Erginus/Archelus, and DSGO-driven Android/Scylla/Siren/Haze. This appendix remains the per-fact source of precise binary locations and evidence grades.

GiantAnt embedded projectile block and BulletType

Evidence: static · Build: steam-678ccb46 · Fact ID: ant-bullet-block

GiantAnt keeps its shot as an embedded bullet block: ant_BulletType (int, default 0) at +0x1670 (read in the constructor 4057C0, 4061CE..406272), the bullet InitParam at +0x1680 (0x1E0 bytes, built by 1001D0; BulletBase at +0x16B0, so objects.md#bulletbase-params gives damage +0x171C, speed +0x1714, life in frames +0x1718, damage reduce 1 +0x1720, damage reduce 2 +0x1728, size +0x1740, ignore-friend +0x1737, team +0x1710; +0x1760 is the InitParam's +0xE0, gravity per enemies.md#humanoid-weapon-fire) and a count +0x1860 right after it. Type 0 is the acid spray of the common ants; type 1 the queen's stream (giantantqueen, e650_giantant_queen, e650_giantant_queen_gold); e662_giantant_queen_red sets 0.

Basis: fn.py reads; the SGO keys by scratch File_Storage/Logs/catalog/obj_keys.py, the key strings by u16_range.py

Addresses (build-specific RVAs unless indicated): 4057C0, 4061CE, 406272, 1001D0

D7700 and D7710 are movaps xmm0, xmm1

Evidence: verified (contributor-reported live byte read on this build; attack-factor interpretation is still source-bounded) · Build: steam-678ccb46 · Fact ID: attack-hook-identity

D7700 and D7710 are movaps xmm0, xmm1; ret: called with [20B2890] (GameStatus) on attack values (the ant's bullet damage 40D478, the bee's 422A5F, the ant's bite values 40D58F / 40D5B3, humanoid bullet damage per enemies.md#humanoid-weapon-fire), they return the value unchanged. So offline an enemy's attack has no difficulty factor beyond its level, unlike durability, which D7720 multiplies by ModeList 3[0] (missions.md#edf6-hp-same-steps).

Basis: original fn.py read of D76E0..D7800; source update reports a live harness peek in M2 Enemy Invaders on Easy (20 November 2026) that read 0F 28 C1 C3 CC CC CC CC CC CC CC CC CC CC CC CC at both entry sites, once per site, with no patch to these functions from the tester's active plugin set. This confirms the identity-function bytes in that reported session, not the complete difficulty-scaling behavior of every attack. Source: Knowledge Hub revision 5b589ca, edf6/enemy-attacks.md#attack-hook-identity.

Addresses (build-specific RVAs unless indicated): D7700, D7710, 20B2890, 40D478, 422A5F, 40D58F, 40D5B3, D7720

Heavy Dango spike attack · static: EDF6_GiantDangoLarge's electrified spikes call UpdateGunBattery 364800 from update 368490; it sets the target point for an embedded GunBattery2 at member +0x1628 and signals a pending fire. That patch design was not tested as part of this source note.

Battery geometry and flags · static: function 364800 requests firing when source object +0x1302 and +0xFE0 conditions hold, writes target point to +0x1640 and battery +0x2D0, and updates request/aim flags +0x2C0. It derives aim from target body/part position relative to raised origin, scales extension by battery charge state (+0x2E0/+0x30) between +0x1650/+0x1654, and randomly positions the muzzle using object RNG +0x3E8 around radius +0xFE4. The battery then runs its own update 6D51C0. The author revised the higher-level description: no actual attack-range check was found **inside this function**, so do not claim it performs the full range gate.

Unverified SGO tuning examples: the large rolling Dango's contact damage note uses an expression resembling 50 + 30 × mark84 × mark2, blast_scale=1, vehicle_blast_scale=0.002 and minimum contact speed 10, with roll target/interpolation/attenuation values 0.2/0.004/0.01 and visual ESB names. Separately E516_BIGGREYBOSS_HANDMUZZLE has a proposed BeamBullet01 (or Acid) projectile item array and GunBattery burst/charge entries, including a source-reported crash when changing a pair. Item ordering and semantics are not a validated full custom-parameter schema.
