EDF6 damage-number HUD: seven native styles, SGO timing, positions and digit formatting

EDF 6Game technical referencesHUD and rendering
Technical reference · Build-scoped static analysis; original contributor evidence grades cited; no new R126 gameplay runtime

Damage values are not displayed by a generic floating text routine alone. EDF6's LYT_HUDDAMAGE.SGO describes seven drawing styles and layout modes; the game projects world anchors into UI space, animates position/color/scale, formats decimal text and queues digit sprites. The original configuration file, not an external editor, owns these defaults.

Seven named SGO styles

Named style Typical native behavior Lifetime in source
hit_every Every hit; a moving per-hit number 0.8 s
AboveIconHistory Fixed recent-number history list 3.0 s
hit Per-target placement 0.8 s
AboveIcon One total over its icon 0.8 s
ReticleSideHistory Recent history beside reticle 0.8 s
ReticleSide One total beside reticle 0.8 s
aim_stack Stack beneath a target 0.8 s

The source identifies these as DamageDispParam_<style> rows. Each row has lifetime, pop fraction and pop size, display rules, spacing and font parameters. Keyframe records are (frame, value, ease); the AboveIconHistory opacity, for example, remains at one through frame 160 then falls to zero by frame 180 during its three-second lifetime.

Projecting world positions

For on-target placement, the game projects both the contact position and that position with a defined world offset. It chooses a minimum 90-pixel vertical gap or the projected 1.25-meter offset, whichever produces the larger displacement. This means the text location depends on camera projection and is not simply a fixed world-space billboard.

Fixed list styles place more recent results first and space each line by a configured count; vehicle display mode additionally scales its displayed numbers. Native default fixed positions differ for Wing Diver, other soldier classes and vehicle mode.

Pop and numeric text

The original pop-size animation uses a cosine ease to shrink an initially enlarged number to normal scale. Its digit formatter has thresholds for two, one or zero decimals rather than a uniform integer rounding rule: under 10, fractions of at least 0.01 use two decimals; under 100, fractions of at least 0.1 can use one. The number texture routine also accounts for a trailing fixed-width sequence when calculating visual alignment.

A rendering quirk noted in source research is that the original digit material constants are applied before the per-number drawing loop. Although each record has its own color values, the shared material can show only one of those colors at a time. The contributor identified this statically and separately tested a modified color-upload path; do not call that behavior a new R126 runtime observation.
