Audio Cues & Custom Sound

EDF 6DocumentationAudio
Technical reference · Community-provided Japanese memo; source-specific and not independently rerun

At a glance

What this page covers: A sound cue is a named playback reference, not necessarily an audio file. A cue may be selected from a preset or referenced by an object, weapon or mission.

How to use it: SEPRESET.SGO describes cue/preset settings; ACB/AWB/HCA resources carry the actual sound data. Checking only an ACB filename can miss the cue name that the game requests.

Evidence boundary: These are workbook-derived loading and editing notes. Confirm the particular game's cue, bank and path before treating a replacement as tested.

An EDF6 sound cue is not equivalent to its .ACB filename. The game may refer to a cue name through a preset, an object resource, a weapon resource or a mission script. Presets describe playback settings; the actual waveform normally lives in ACB/AWB/HCA data.

Loader path overview

  • SEPRESET.SGO acts as a list of cue/preset settings (name, volume and other playback options) and does not contain the original audio waveform.
  • An ACB may contain multiple cues, and a cue can select several samples or different playback properties, including random pitch and looping.
  • In weapon SGO, the memo reports a working path by naming the cue and declaring its actual sound file as a resource. In object SGO, preset-form sound references were also used.
  • For mission AngelScript, PreLoad(...) is the documented way to load a resource first; some proposed combinations of PlaySE/BGM remain not directly verified in the memo.

Negative results and caveats

  • Merely referencing SEPRESET in a weapon resource failed in several trials. The author suspected the preset might be loaded only at game startup; this mechanism was not proven.
  • ACB output produced by a tested newer CRI ADX Atom Craft LE 3.55.00 was incompatible with the author's EDF6 player test. They instead replaced sound data inside an existing ACB using tools and re-encoded HCA content. A format-version mismatch was suspected, but the exact validation cause remains unverified.
  • Existing cue-level loop settings can complicate replacement; copying a simpler cue structure was the reported workaround.

The notebook includes direct positive/negative experiments on weapon EWEAPON049 and the vehicle VEHICLE403_TANK. Do not generalize one cue test into universal support for every audio format.

For sound positioning and Doppler see Spatial audio.
