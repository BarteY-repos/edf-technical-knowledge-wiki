EDF5 controls: keybinding codes, class pages, conflict rules and CFG layout

EDF 5Game technical referencesInput and UI
Technical reference · Attribution and grade per source fact; this edition adds no game runtime test

EDF5 stores bindings as integer input codes, not textual key names. In the source's examined build, a per-player binding block contains 10 categories with 255 action slots in each category. The native menu exposes only named subsets of those slots, and the rest are not proof of usable user-facing controls.

Code domains

Code range Device / meaning
0 Unbound
1–0x0B Gamepad A/B/X/Y, triggers, shoulder buttons, sticks and Back
0x0C–0x11 Mouse buttons, wheel and side buttons
0x12–0x78 Keyboard keys from the game's own lookup table

The keyboard list includes letters, digits, numpad keys, F1–F12, modifiers, arrows, navigation/editing keys and several locale-specific keys. These are internal game codes, not Windows virtual-key values and not automatically DirectInput scan codes.

Menu pages and action groups

Page kind Native action range Group
0–1 0x00–0x14 Gamepad pages
2 0x15–0x20 Common keyboard
3 0x21–0x27 Soldier classes
4 0x28–0x2F Fencer
5 0x30–0x34 Drive
6 0x35–0x37 Tanks
7 0x38–0x3C Combat Frame
8 0x3D–0x41 Bulga
9 0x42–0x46 Depth Crawler
10 0x47–0x49 Helicopter

The source's per-class categories 0 Ranger, 1 Wing Diver, 2 Air Raider, 3 Fencer contain overlapping common actions. A given menu label can be class-dependent: “Dash/Boost” represents different movement for Ranger and Wing Diver, and may not appear for Air Raider.

Duplicate bindings and reserved codes

The menu's assignment routine swaps a chosen key with another action on the same page that already uses it, rather than simply permitting arbitrary duplicates. A separate conflict routine reports 0 reserved, 1 already selected, -1 available. Some assignments are mirrored across soldier-class categories when the page item carries a shared-action flag.

One action stores one int32 code. The surveyed table does not encode modifier chords such as Alt+B as a compound key, even if the underlying OS can detect modifiers; an external remapper and the native binding table do different jobs.

Persistent configuration and scope

The source places the table in the game's COMMON.CFG representation, following camera-setting fields, with an address formula based on player, category and action index. It also traces the menu text to localized OptionPlayer_Keyboard* strings. These addresses belong to the studied EDF5.exe; do not use them as universal offsets for every distribution or patch version.
