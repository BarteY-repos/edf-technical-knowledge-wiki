Mission RMPA 141-mission record catalogue: paths, regions and spawns

ConversionGame technical referencesMissions & ScriptingEDF 5EDF 6
Technical reference · Source-corpus/static reverse-engineering; no new game runtime test

Scope and provenance. These are measured reference EDF6 mission RMPA files paired with the clean EDF5 source corpus for the 112-base-union, 15-DLC1 and 14-DLC2 set. They are not counts hardwired into the RMPA specification or proof that 141 missions were finished in EDF6 gameplay. Exact rows are in the companion CSV.

What this corpus actually contains

Record class Observed across 141 missions Meaning
Route groups 511 Paths owned by missions, not map NAV polygons
Waypoints 5,103 Route members using global waypoint.no in EDF6
Shape groups 305 Mission-owned named regions / shape collections
Shapes 1,355 Named regions with type, GID and payload
Spawn groups 685 Mission-owned spawn collections
Spawn records 3,387 Named spawns with two coordinate vectors

The paired source/target audit preserved route GIDs, route next topology and widths for 5,103/5,103 waypoints; shape type/GID for 1,355/1,355 and spawn GIDs for 3,386/3,387. The sole recorded spawn-GID exception is DM018 player 27 → 0 in the historical reference port. Do not conflate the semantic ID with the sequential waypoint.no field.

How to interpret exceptions

  • Five target route groups and eleven target spawn groups are empty. Separately, the pair audit finds 21 reference-only empty groups (5 route + 5 shape + 11 spawn) in 18 missions; these are not necessarily identical inventory concepts.
  • Almost every shape has standard target Usage / 通常 metadata (1,354 of 1,355). M061 has the single exceptional camera-named reference shape without that descriptor; it is not evidence for a generic no-metadata rule.
  • The adjacent reference-tuning casebook lists why static name closure and actual gameplay behavior must be kept separate.
  • MISSION.RMPA binary layout describes record sizes, alignment and the route-local-to-file-global numbering conversion.
