EDF5 enemy names: SGO classes, kill counters, statistics labels and mission briefings

EDF 5Game technical referencesEnemies / identification
Technical reference · Source analysis only (unless a source fact is contributor-verified); no new EDF runtime test

EDF5 uses at least three naming layers for its enemies. The C++ class or xgs_scene_object_class is the engine's implementation family, an SGO is the particular configured object, and a localized name may be present in the statistics screen or a mission briefing. The three are not interchangeable.

How names are grounded

An enemy definition's game_object_kill_counter can name a statistics counter. The English text table etc/texttable_xbox.en.txt_sgo includes StatusInfo_<counter> entries that describe the corresponding game statistic. Examples from the source comparison include:

The exact family/counter mapping is defined by each SGO; the names above are a reader-facing paraphrase of the recorded label census, not a claim that all subtypes get their own status counter.

Specific variants are sometimes named only in missionlist.*.txt.en.sgo briefing text, for example “red drones,” “heavy-armored aliens,” “bombers,” “golden aggressors” and “silver aggressors.” Names that appear in an external radar catalogue but not in either game's localizable strings are catalogue/wiki names, not proven official UI labels. The AntHillKillCount localization says “Teleportation Devices” even though the associated e517_antHill SGO is catalogued as a giant ant hill.

Important mismatches

The EDF5 class DragonSmall is the Tadpole, not a dragon enemy in EDF5's played campaign. Nephila refers to the web-spitting Aranea (the related EDF4.1 type is often called Retiarius). Treating an internal class or filename as a literal bestiary label would misidentify both.

The original contributor verified the general Tadpole/Aranea identification from game knowledge; the exact kill-counter localization and briefing scans are static source analyses, not a fresh screenshot comparison with the English game UI.
