Mission corpus scope — corrected final classification

UniversalMissions & ScriptingMissionsEDF 5EDF 6
Source-backed research / case study · Reference

Evidence level: Historical reconciled source; not automatically current authority. Check newer domain-specific findings.

The old statement “145 missions = full corpus” is superseded. The supplied EDF5 tree contains 335 MISSION.BVM files:

  • 141 shipping-required missions — primary canonical completeness gate;
  • 10 source orphans — nonblocking research fixtures;
  • 126 EDF4.1 subtree — future scope;
  • 56 TEST missions — nonshipping fixtures;
  • 2 TGS/demo missions — nonshipping.

The current mod's 145 AC corpus is still useful as a stress/regression set: all 141 shipping missions plus M032, DLC/DM006, DLC/DM008_2 and DLC/DM099. Those four extras add no unique cuscall key or VM mnemonic beyond shipping141.

Shipping composition is 112 base-union + 15 DLC1 + 14 DLC2. Base binary LIST.SGO evidence gives 110 offline, 111 online; M000 is offline-only, while M082 and M083 are online-only in the original active EDF5 source lists and therefore still shipping-required.

Clean EDF5 source versus EDF6-stored legacy BVMs

The 141 shipping-required missions were inspected against original EDF5 MISSION.BVM source files, not treated as byte-identical to the similarly named EDF5_OLD_SCRIPT files contained on the EDF6 side. In the exact paired corpus, 0/141 legacy BVMs were byte-identical to the clean EDF5 source: 65 files were 80 bytes longer and 76 were 96 bytes longer. Source-byte identity and a matching mission ID are therefore different claims. See clean EDF5 BVM versus EDF6's EDF5_OLD_SCRIPT for the verified scope, spawn-transaction counts and the offline/runtime boundary.

EDF5 DLC mission ordinals — source LIST authority (2026-08-27 correction)

Never infer a displayed DLC mission number from the DMxxx suffix, filesystem sorting, corpus enumeration, or a current mod-pack folder order. The authoritative ordinal is the row order in the original EDF5 binary mission LIST tables. For DLC1, DLC1_MISSIONLIST.OFFLINE.LIST.SGO and DLC1_MISSIONLIST.ONLINE.LIST.SGO are byte-identical (SHA-256 2f1ec09fe48f8bacb68c0117d37eb17a94ca52dd2ce43166ab54c79c4d8761d2) and contain 15 rows.

EDF5 DLC1 display order is: 1 DM011, 2 DM013, 3 DM005, 4 DM018, 5 DM019, 6 DM020, 7 DM008, 8 DM003, 9 DM014, 10 DM003_2, 11 DM001, 12 DM007, 13 DM003_3, 14 DM013_2, 15 DM015. Therefore DLC1 mission 11 is DM001, DLC1 mission 13 is DM003_3, and DM018 is DLC1 mission 4. Any historical/current note implying DLC1 #13 = DM018 is superseded.

EDF5 DLC2 display order is: 1 DM005_2, 2 DM002, 3 DM021, 4 DM006_2, 5 DM009, 6 DM007_2, 7 DM010, 8 DM014_2, 9 DM012, 10 DM022, 11 DM023, 12 DM024, 13 DM017, 14 DM016. Use this same source-LIST rule for future ordinal→technical-ID resolution.

Deployment bug distinct from transpiler

The supplied current mod has MISSIONPACK03 ONLINE LIST.SGO byte-identical to OFFLINE. It therefore exposes only 139 unique shipping missions, omits M082/M083, and exposes tutorial M000 online. Companion JSON lists are stale and are not runtime truth. Fix this only in the deployment/list-generation subsystem after semantic transpiler promotion; do not shrink transpiler scope to match the broken mod list.

Resource registration is separate from mission eligibility

An observed MISSIONPACK03 ONLINE LIST was byte-identical to OFFLINE; M082/M083 were omitted from the deployed online table even though the underlying source mission corpus includes them. Likewise, a working game menu depends on image-RAB lookup, localization and pack registration, not only a correctly compiled script. See mission LIST, images and deployment identity. Do not reduce the converter's supported mission set to match a defective deployed LIST.

Original versus converted LIST counts must remain distinct

The native EDF5 base LIST tables audited in the original R37 source have 110 OFFLINE and 111 ONLINE rows, with 112 unique base mission IDs. The historical converted R41 content pack (which had already changed membership) instead has 112 OFFLINE / 111 ONLINE rows, while the later EDF6 target uses 112 / 112 deliberately for shared ordinal-based save progress. These statements describe three different data sets, not contradictory counts of the same source file. A side-by-side reader table is in EDF5 source versus converted mission lists.

Exact source-orphan filenames and census partitions (consolidated)

The 335-file inventory is a tree census, not a count of playable EDF5 missions. Breakdown: 141 shipping (112 base-union + 15 DLC1 + 14 DLC2), 10 source orphans, 126 EDF4.1, 56 TEST and 2 TGS files. The original mode lists hold 110 offline and 111 online entries, with distinct base union 112.

The ten nonshipping source orphans are E5M001, E5M002, E5M003, E5M004, E5M005, M032, DLC/DM006, DLC/DM008_2, DLC/DM012_BAK, DLC/DM099. Historical stress coverage used only four of them (M032, DM006, DM008_2, DM099) in addition to shipping 141. The static census found no additional VM mnemonic or custom-call key among these orphans, but does not establish identical mission contents. Source: original EDF5 edf5/mission-vm.md, bvm-corpus-335, bvm-shipping-141, bvm-orphans (static steam-5d11de53).
