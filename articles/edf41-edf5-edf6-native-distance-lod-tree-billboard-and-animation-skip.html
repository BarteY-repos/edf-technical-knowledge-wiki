EDF4.1/5/6 map LOD: tree billboards, building switches and distant animation frequency

ConversionGame technical referencesRendering and map LODEDF 4.1EDF 5EDF 6
Technical reference · Source-derived; evidence grades and build restrictions described in article; no new EDF runtime

All three examined games use camera-distance-dependent model selection for map trees, structures and other props, but the default distances and engine controls differ. The same source also records a separate distance-dependent animation update skip, which should never be confused with mesh LOD or with animation being absent.

Mesh → billboard → cull for trees

In each studied generation the tree renderer compares a squared camera-distance metric to squared thresholds from the map's .trb definitions. Below the near threshold it draws the mesh; in the near-to-far band it blends full mesh and billboard; farther away it draws the billboard where available; past the cut-off it draws neither. Some pass types do not submit the billboard. The camera-distance factor has an additional view-dependent multiplier whose writer was not resolved consistently in all studies.

Game Native .trb examples Evidence scope
EDF4.1 Most trees: 10 m near, far often 110–250 m; selected city street trees start at 50 m 96 .trb examples across the studied map set
EDF5 Most trees: 50 m near, often 100–180 m far; bushes commonly 10/50 m 149 entries in the studied all-map enumeration
EDF6 Trees on HEIGEN507: 50 m near, 100–180 m far, usually 1000 m cut-off; bushes 10/50 m 19 local .trb entries in one named map

The EDF6 example is not an all-map census and should not be compared numerically with the wider EDF4.1/5 corpora as if they sampled equally. A billboard texture must also exist; otherwise a far-distance selection may render nothing.

Buildings are not smoothly crossfaded in the studied builds

Placed building structures have up to three model choices. The engine selects a level based on LOD distance fields in MAPB and the corresponding part fields in MAPO; when both specify thresholds, the larger defined value is used. The observed native renderer hard-switches between structure LODs rather than smoothly dithering from one to another. A contributor verified a plainly visible EDF6 building pop when walking a small step in a city scene.

Common squared-metre fields explain thresholds that otherwise look too large:

Field value Equivalent distance
6,400 80 m
10,000 100 m
22,500 150 m
40,000 200 m
90,000 300 m

Across EDF4.1, 3,011 of 4,632 sampled placed category-1 .mosb buildings used the 150 m first LOD with no second LOD; EDF5's 8,365 placed buildings included 2,854 such 150 m/no-second-LOD cases. EDF6 included several frequent two-threshold pairs, such as 200/300 m or 100/300 m, and a separate 150 m/no-second-LOD class. These are observed frequency tables, not map-independent rendering contracts.

Distant animation updates are another knob

The generation crosswalk identified pose-job frequency reduction for EDF5 and EDF6 insect actors. In EDF5, the native distance bands can update poses once every 1, 4, 8 or 16 normal job slots; for humans the corresponding path is gated by human_frame_skip_enable and is usually disabled by default. EDF6 insects use corresponding bands, influenced by insectbase_AnimationLodAdjust from SGO data. EDF4.1 had the mesh LOD selector but no corresponding animation skip was found in the inspected paths. That is a negative-search result, not proof no skip mechanism exists anywhere in the game.

EDF4.1 uniquely exposes set_lod_distance_scale, which changes several distance-scale globals (the chara family is treated separately). EDF5 did not have the corresponding global distance-scale control in the researched build; EDF6 uses distinct global structure scaling values. Nothing here establishes that changing any of these controls is safe for performance, shadow passes or other map content.

What this comparison does and does not establish

Three independent systems matter: tree billboard selection, building mesh LOD and skeleton/pose scheduling. Changing a mesh selection threshold does not force new animation frames, improve an existing source texture, or solve foliage alpha blending. Likewise, retaining distant full-resolution meshes can increase draw or visibility cost.

Evidence: source-code/disassembly and named-map asset studies, plus one contributor's observed EDF6 building pop. No new game run was performed for this article.
