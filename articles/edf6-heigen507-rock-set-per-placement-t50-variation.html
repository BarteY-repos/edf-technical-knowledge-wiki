EDF6 HEIGEN507 rock sets: T50 graphs vary per T2 placement

EDF 6Maps & NavigationRock destructibles and per-placement T50 graphs
Technical reference · Native source-corpus/static binary evidence, runtime limitations stated explicitly

An EDF6 native MAPB T1 object family does not always identify one universal destruction graph. The five IG_HEIGEN507 rock-set families examined here have one MAPO slot per placement, four p58 pieces per placement, and stable body/resource ownership, yet their T50 graph differs from one placed T2 instance to another.

All five families were observed to have one stable slot pattern, one p58 group schema, one MAD body set and one RAB closure each. Together their native body-set union contained 20 distinct bodies and their family resource closure 22 RAB assets (without a separately required shared donor reference).

The variation is not caused by a different number of mesh slots or a different rock body type in each placement. The changing information is the T50 topology attached to its specific placement.

Exact per-placement identity matters

A converter cannot safely cache one T50 template under the T1 resource name and reuse it for every T2. Doing so can silently change which rock fragments are connected, even when all referenced geometry, p58 pieces and collision bodies are identical.

The stable native association is:

MAPB T1 rock-set family
    ↓
MAPB T2 exact placement / variant
    ↓
MAPO slot -> p58 four indexed pieces
    ↓
MAPO T50 associated with this exact T2
    ↓
MAD bodies used for those piece indices

An offline enumeration verified 96/96 placements without coercing any to a different template. A separate composition of all 55 distinct graphs preserved exact parsed T50 semantics and passed basic MAD structural checks; no new EDF6 runtime test accompanies this evidence.

This is distinct from the NW_EUROPE01 multi-storey buildings, where T50 often connects different building slots. The HEIGEN rocks show that placement-specific T50 variation also occurs inside a single slot with a fixed four-piece set.

Scope and unresolved questions

The evidence covers these five named native rock-set resources; it does not establish that all EDF6 destructibles vary per T2, or explain why each HEIGEN placement receives its exact graph. A generic proximity or radius-based generator remains unverified. If faithfully reusing a native placement, preserve its T2 → T50 identity; if authoring new fragments, do not present a guessed graph as exact Sandlot output.
