EDF6 destructible props: static bodies, dynamic debris and native Havok material profiles

EDF 6Maps & NavigationCollision & Physics
Technical reference · Bounded HEIGEN native donor; authored bodies validated offline only

An EDF6 map prop that changes from intact to destroyed is more than two visual MDB meshes. The retained native destructible-body examples include separate physics body roles, motion properties and mass distribution data in Havok/MAD. For a custom collision writer, preserving only the mesh shape without these roles is not sufficient to match the observed native profile.

Native single-slot example

In the examined HEIGEN507 native map, a single bounded reference model was used to understand the schema. The resource was sk_rock501a_l.mdx (T1 slot 5), with one p58 group and one piece. Its paired bodies had these measured properties:

Role Referenced native Havok body Motion Mass Motion properties
Intact / primary sk_rock501a_l.polymsh1 motionType=0 (static) Not used as the dynamic debris mass Native source profile
Broken debris sk_rock501a_l_hk.polymsh1 motionType=2 (dynamic) 5.0 ID 1, with valid mass distribution reference

For the tested pair the pose is identity; the XYZ components of linear/angular velocities are zero. The stored vectors have four components and the source contained a non-zero W value. Treating the whole vector4 as ordinary XYZ velocity and demanding W=0 incorrectly rejects a legitimate native reference.

A valid native-looking dynamic body also requires a hknpRefMassDistribution and a valid motionPropertiesId; do not produce a decorative debris mesh whose physics record has an uninitialized mass distribution.

Rebuilding from authored geometry

The retained tests generated new authored collision shapes and identities while using this native reference only for bounded system/material/quality/motion/mass semantics. The native shapes were not imported into the custom map.

The standalone two-prop test yielded 7 MAD bodies (3 base, 2 authored static, 2 authored dynamic), with each debris body mass 5.0 and valid motion properties. A larger mixed-source test retained 500 native bodies alongside four authored bodies, for 507 total. Both passed source-only MAD wire, first-primitive-index and compressed-mesh broadphase checks and were A/B byte-identical.

These results show that static/dynamic body roles and mass distribution can be generated coherently at the binary structural level. They do not prove the game will trigger replacement, spawn debris, preserve the expected collision/motion or restore it after reload.

Practical implications

  • Do not infer a complete destruction system merely from the appearance of *_hk resources or a CrashType field.
  • Keep the intact body and dynamic debris body as different motion roles.
  • Preserve validated motion property IDs and mass distribution semantics for the exact reference family.
  • Use the 3D vector components to check initial zero velocity; do not reject a valid vector4 because the padding/auxiliary W lane is nonzero.
  • Recheck collision broadphase and first-primitive-index invariants after composing native and authored geometry.
  • Treat damage triggering, broken-visual replacement and runtime debris physics as independent gameplay validation questions.

The numeric 5.0 mass, ID 1, and motion types 0/2 are scoped to the named HEIGEN reference. They are not globally required for all EDF6 destructible props, nor is this source-only result a runtime claim.

For module-to-module destruction, see T50 collapse connectivity. For collision check pitfalls, see Havok broadphase validation.

Placement-specific T50 is independent of the Havok body set

The five native HEIGEN507 sk_rock50[1-5]a_set.mdx families collectively have 96 placements and 55 distinct T50 graphs, despite each family having a stable four-piece p58/body relationship. A body set that is structurally valid in MAD is not enough to recover the placement's destruction edges. Consult HEIGEN507 per-placement rock T50 graphs.
