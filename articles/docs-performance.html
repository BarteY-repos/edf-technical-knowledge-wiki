Overview

EDF6 performance and frame-rate modifications must distinguish render/presentation cadence from game simulation and timing. Raising FPS or changing input polling can affect subsystems differently, so a visual framerate increase does not prove safe gameplay timing.

Validation

Check timer consumers, physics, mission events, gameplay, menu/rendering and input independently. Source/static checks are not runtime proof. Preserve branch-specific status rather than claiming a universal 120 FPS patch.
