Official Sandlot oracle

The verified native EDF6 mission corpus used for claims about official EDF5 ports is:

MISSION_EDF6_NATIVE_FULL_2026-09-06.zip
SHA-256 1434b5e1a3c2ad0352b1e86e39d0a1bd4867e073d15f4f5bf202ac462b8cbb22
MISSION/EDF5_NEW_SCRIPT/*/MISSION.AC
exact mission count: 44

Only this exact44 corpus, or another independently verified extraction of the same native game data, may support statements such as “Sandlot does X”, “official EDF5_NEW_SCRIPT does X”, or exact-pair semantic conversion claims.

Third-party corpus that must not be promoted

A community mod archive also uses an EDF5_NEW_SCRIPT directory name but contains 115 mission AC files under a mod path. Its verified classification is third-party mod content, not Sandlot/native authority.

EDF5 Missions in EDF6(support online).zip
SHA-256 aaa706f997778ff662dbd3657d7357cbaf389181b1b1c49c812e887861bdc94b
mission count: 115
classification: third-party mod

Do not assume: A directory named EDF5_NEW_SCRIPT implies native or official provenance.

Implementation rule

When deriving conversion laws, opcode semantics or exact-pair differences, attach provenance to the source pair before interpreting the bytes. Community conversions can be useful compatibility references, but they cannot override native/Sandlot evidence.

This rule is especially important when a third-party package contains plausible-looking complete mission coverage that exceeds the 44 verified native ports.
