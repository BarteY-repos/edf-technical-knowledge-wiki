EDF6 Havok tagfile internals: packed integers, TBDY schema and ITEM references

EDF 6Game technical referencesFile formats / Havok
Technical reference · Source analysis only (unless a source fact is contributor-verified); no new EDF runtime test

The Havok TNA1 and TBDY streams use variable-length packed integers. Ordinary leading patterns are 0xxxxxxx (1 byte, 7 bits), 10xxxxxx (2 bytes, 14 bits), 110xxxxx (3 bytes, 21 bits) and 111xxxxx (4 bytes). TNA1 additionally recognizes 0xE8 followed by a big-endian u32, used for large numeric values. Type and member names are referred to by an indexed string table padded with 0xFF.

TBDY is not a stream of ordinary C structs. It specifies a packed type index, parent, flag mask and optional sub-type flags, version, serialized size/alignment, member descriptors and interfaces. The known sub-type families distinguish bool, integer, float, pointer, class, array and tuple. For example the source identifies type flag 0x05 for floating point, 0x06 for pointer, 0x07 for class and 0x08 for array. These describe the serialized DATA layout, which need not equal x64 runtime class memory offsets.

ITEM references

INDX/ITEM contains 12-byte records. Record zero is null. Each record stores the item flags/type index, offset from DATA's start and element count. Pointer, array and string fields inside DATA store u32 item indices rather than native memory pointers.

Value concept Native tagfile representation
hkRefPtr<T> and T* u32 index into ITEM
hkArray<T> u32 item index; length obtained from ITEM
hkStringPtr u32 index to a NUL-terminated char item
hkReal little-endian IEEE float32
hkHalf16 upper 16 bits of float32 (bfloat16), not IEEE binary16
Tuple Fixed-size type-defined sequence

The source has not decoded hkUFloat8 in this corpus. It would be incorrect to describe it using a guessed IEEE half/byte mapping. Likewise an unused type declaration in TNA1 may have no corresponding TBDY object entry when no instance requires it.
