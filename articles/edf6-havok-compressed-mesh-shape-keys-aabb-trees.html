EDF6 compressed-mesh shape keys and two-level AABB acceleration trees

EDF 6Game technical referencesPhysics / collision topology
Technical reference · Source analysis only (unless a source fact is contributor-verified); no new EDF runtime test

In the EDF6 compressed collision profile, the observed shape key is a section/primitive combination: section_index << 8 | primitive_index << 1, with the low bit selecting the second triangle of a quad. Source fields numShapeKeyBits, maxKeyValue and numPrimitiveKeys describe key storage and triangle coverage. The corpus has a recorded exception to one naïve key-width relationship, so using only the number of primitives to predict key width is not generally reliable. An all-ones value can also collide with sentinel use if key width is underestimated; the separate MAD source research records this problem.

The native AABB structure is hierarchical. Each section has a packed Aabb4BytesCodec tree that divides its primitives. The mesh has a top Aabb5BytesCodec tree over sections. Nodes are stored in preorder. An inner section-tree node encodes an offset to its right child while its left child is the next node; a leaf encodes the primitive index. A source formula maps each child min/max axis to low/high nibbles within its parent AABB.

The author reconstructed the section-tree quantization from 2,400 axis values in the convex-only corpus with byte-identical results. That is strong evidence for these serialized field rules, but it is not equivalent to proving the game’s own physical collision outcome for newly constructed meshes. The top tree uses a different 5-byte codec and must not be decoded with the section-tree rule.

The source also notes that an outer shape's numeric key does not by itself identify the visible object material or NPC owner: those require the collision material and game-object context in the enclosing HKT/SHKT graph.

Source: EDF Knowledge Hub edf6/havok-format.md, facts compressed-mesh-keys, compressed-mesh-trees; independent MDB/MAD key-width source guidance remains separate.
