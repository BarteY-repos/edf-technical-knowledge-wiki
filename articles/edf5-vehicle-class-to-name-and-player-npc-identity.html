EDF5 vehicle class crosswalk: tanks, helicopters, bikes, cars and mechs

EDF 5Game technical referencesVehicles / native classes
Technical reference · Source analysis only (unless a source fact is contributor-verified); no new EDF runtime test

EDF5 mostly uses the same C++ class for a vehicle's player-summoned, AI-driven and parked mission variants. Its owner, driver, ride link and SGO setup determine whether it behaves as the player's vehicle, an ally-operated vehicle or an empty map object.

V505_TANK, V505_TANK_AI and V505_TANK_MISSION can all resolve to Vehicle505_Tank. NPC soldier SGOs similarly use player-style classes (AssultSoldier, HeavyArmor, PaleWing) while loading different weapons and behaviour settings.

The source did not identify an in-game vehicle for Vehicle511_Bike; that mapping remains unknown. The grouping into tanks, helicopters, bikes and mechs is editorial rather than a discovered native base-class hierarchy. Depth Crawler is separated because its wall/ceiling traversal is mechanically different.
