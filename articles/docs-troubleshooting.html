First identify the failing layer

Symptom Useful first checks
Map renders but collision fails MAD/Havok shape, registry, root and runtime body composition — Collision and navigation architecture
Model parses but game crashes Typed loader registration, MDB vs .trb, and CMPL payload — Loader dispatch case
Mission LIST works but gameplay is black Mission path/provider, BEFORE.BVM UI fade and AC start — BEFORE scenes
AI walks into geometry NAV donor mismatch, NVMD and mission route — Navigation
Local player works, online peer desyncs Distinguish RUDP, shot/damage event owner and EOS state — Networking
Material looks wrong Shader family, typed parameter order, textures and alpha state — MDB material parameters — roughness, metallic and normals

Reliability tags

  • Runtime observed: a specific installed build and scene were tested.
  • Native binary: facts measured from original target assets or disassembly.
  • Source/static: a converter or serializer generated consistent data offline.
  • Hypothesis / open: not enough evidence for a general rule.

See Evidence standards, Known invalid shortcuts and Open questions. Do not turn an accepted compatibility exception, such as omitted 3450, back into a global blocker.
