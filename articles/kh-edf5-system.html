Observations

The "close the game?" question: the jz at 60AFA3 decides whether mov byte 1412535FA,1 runs

Evidence: static · Build: steam-5d11de53 · Fact ID: close-game-dialog

The "close the game?" question: the jz at 60AFA3 decides whether mov byte [1412535FA],1 runs; Quarri6343's SkipCloseGameDialog NOPs the jz, so the flag is always set and the question is skipped (what the flag means exactly is not decoded).

Basis: the patch's anchor, decoded

Addresses (build-specific RVAs unless indicated): 60AFA3, 1412535FA

Attribution: Quarri6343 (SkipCloseGameDialog), novae (ajane)'s EDF5 outside set · 2026-10-16

Invalid online mission ID table crash

Evidence: static · Build: steam-5d11de53 · Fact ID: mission-id-bounds

Online, an invalid mission id crashes the game: at 556297 the code indexes a table of 12-byte entries with r12 (lea rcx,[r12+r12*2] / lea rax,[rdx+rcx*4], then follows two relative offsets at +8) without a bounds check. Souzooka's InvalidMissionIDFix calls a check that compares the index with the count dword at [table-8] and skips the entry when out of range.

Basis: the patch's code; the original instructions decoded at the fixed address

Addresses (build-specific RVAs unless indicated): 556297

Attribution: Souzooka (InvalidMissionIDFix), novae (ajane)'s EDF5 outside set · 2026-10-16
