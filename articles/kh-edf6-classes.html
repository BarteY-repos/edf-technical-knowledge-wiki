A family test without calling __RTDynamicCast: from the primary vtable's [vt-8] complete-object locator (signature 1, offset 0) read the class hierarchy descriptor (locator +0x10 RVA), its base count (+8) and base array (+0xC RVA) and compare each base's type-descriptor RVA. Basis: the author's RTTI reading ("H", type-descriptor names read at TD +0x10); agrees with netcode.md#net-walk-sync-control and damage-model.md#dn-class-vtables where they overlap

FadeUtility and DamageNumber runtime classes

Evidence: static · Build: steam-678ccb46 · Fact ID: fade-damage-number-rtti

EDF.dll keeps EDF5's FadeUtilityClass (edf5/mission-flow.md#mission-rtti-classes) and has a native DamageNumberDraw class (hud.md, crosswalk/damage-numbers.md): one RTTI type-descriptor name each, at file offsets 205E4B8 and 2063870 (file offsets, not RVAs).

Basis: the EDF5 project's RTTI and string spot checks (no build recorded); both names re-found in the pinned EDF.dll by a byte search (KH chat 60, scratch File_Storage/Logs/rtti_find.py)

Attribution: novae (ajane), hub read · 2026-11-08

Humanoid_Basic superclass and animation callbacks

Evidence: static · Build: steam-678ccb46 · Fact ID: humanoid-monster-bases

Humanoid_Basic -> HumanoidBase -> GameObjectBase, also deriving from xgl::anm::CASController::UserCallback and bvm::C_Process (a BVM script process; the Humanoid custom-call dispatcher 467200 serves its AI script calls, enemies.md#humanoid-ai-weapon-calls); Monster501 -> MonsterBase -> GameObjectBase (EDF 4.1's Monster501 derives from GameObjectBase directly).

Basis: same audit

Humanoid child weapon message fan-out

Evidence: static · Build: steam-678ccb46 · Fact ID: humanoid-weapon-ex-dispatch

A Humanoid fires several child weapons through one message: it keeps its humanoid_base_weapon_ex entries in a vector at Humanoid+0x1120 (count +0x1130), builds a per-slot mask (1 << slot) in the update region 47143A..4716EB, and the receiver 4740B0 walks the vector and, for each child whose bit is set in the mask, calls the child's virtual +0x78; for EDF6_MartianWeapon_Basic that is 455E80. The custom-call dispatcher of the same class is 467200. Details: enemies.md#humanoid-weapon-ex-list and #humanoid-fire-mask-message (message type 0x11), crosswalk/multi-weapon-enemies.md.

Basis: the source's static trace; the curator decoded the receiver's loop ([rbp+0x1130] count, entries read from [rbp+0x1120], shl eax,cl; test r14d,eax), KH chat 36

Addresses (build-specific RVAs unless indicated): 4740B0, 47143A, 4716EB, 455E80, 467200

Attribution: EDF41-to-EDF6 handoff (Bartey), engine-abi table and Hector carrier audit, novae (ajane) · 2026-11-06

HectorBridge original hook byte sequence

Evidence: static · Build: steam-678ccb46 · Fact ID: hectorbridge-hook-site

The HectorBridge hook site 4716CD in that region: its original 14 bytes 8B D3 48 8D 8D 70 04 00 00 E8 A5 3E E4 00 are mov edx, ebx; lea rcx, [rbp+0x470]; call 12B5580 (the native writer), continuing at 4716DB. The source's Hector plugin experiment hooked here; Hector-specific runtime and network behavior was never qualified.

Basis: bytes and instructions matched against EDF.dll by the curator (fn.py), KH chat 36

Addresses (build-specific RVAs unless indicated): 4716CD, 12B5580, 4716DB

Attribution: EDF41-to-EDF6 handoff (Bartey), novae (ajane) · 2026-11-06
