EDF5 MissionPack03–05 LIST/TXT/image parity: exact static audit

ConversionMissions & ScriptingMissionsEDF 5EDF 6
Technical reference · Historical exact source and offline static audit; runtime correction specifically noted

Scope: recorded 2026-09-02 offline static acceptance of the EDF5-derived MissionPack03–05 resource set on the studied EDF6 target profile. This is a precise reference for how to verify a bundle; it is not an assertion that every new deployment has identical artifacts or that an offline gate is a gameplay runtime pass.

The cross-file invariant

For this target, OFFLINE and ONLINE share one save/index axis. Every mission position must agree across the mission LIST, localized TXT title/brief arrays and the image entry resolved by LIST field2. The mode-specific gameplay profile can still differ via CONFIG/ModeList despite identical LIST and TXT data.

In the R4 fixture, corresponding OFFLINE and ONLINE LISTs were byte-identical within each pack, with zero missing/extra/duplicate mission names and all 15 underground flags=40 rows matching the mapped underground missions. The equality is intentional for the index, not for the gameplay balance.

Localization audit: five tables, two modes, three packs

The fixture checked EN, JA, KR, CN, and SC for every pack and mode: 30 localized TXT combinations. Every combination matched its LIST row count and was byte-identical between ONLINE/OFFLINE for the same language and pack.

A previous R2 parity attempt changed MP03 ONLINE LIST to 112 rows while leaving its ONLINE TXT at 111 rows. Its record N could therefore show another mission's title or brief even when mission loading was correct. The R3 resource parity audit found this, and the R4 fixture corrected it.

For MP03, missing M082/M083 source title rows were filled using the EDF5 ONLINE text source, separately for each locale. Do not synthesize an English row into all languages or assume a successful LIST parser proves localized ordinal alignment.

The shared mission image archive

The preceding shared-image baseline had 286 entries (147 native EDF6 + 139 EDF5). The R4 source audit appended exactly two missing EDF5 image entries, EDF5_M082.dds and EDF5_M083.dds, yielding 288 entries (147 EDF6 + 141 EDF5) while preserving all existing 286 entries.

The audited shared OFFLINE/ONLINE image RAB outputs had identical SHA-256:

711a6430bad870d637d5eea79954dd417c909f2ddfb74c2cce61b24eae149ccc

This is a fixture-specific checksum, not a universal archive signature. The retained source notes RAB version 272 and entry kind TEXTURE. The archive is not packaged in this wiki.

CONFIG and deployment boundary

The R4 resource bundle intentionally did not overwrite CONFIG.SGO. The retained R43 CONFIG had already been checked for appropriate mode-specific LIST/TXT/image routing, and replacing it would have overridden unrelated mod merges. In another target profile, failing to include or reconcile the right CONFIG binding can leave a correct archive unreachable.

Minimal validation sequence:

  1. Check the pack identity, target mission ordinal and deployed LIST row in both modes.
  2. Verify field2 references an entry in the actual shared runtime image RAB.
  3. For each of the five languages, check TXT count and exact ordinal mapping against LIST.
  4. Confirm flags=40 on the audited underground set and standard 8 on other rows.
  5. Check mode-specific CONFIG gameplay profiles separately from shared metadata.
  6. Observe actual mission selection, title/thumbnail and eventual gameplay in runtime before claiming a complete port.

See shared progress/metadata, mission previews and underground runtime restrictions.

Why the historical underground patch reported 29 changed records

The 15 underground mission IDs would produce 30 mode-scoped LIST entries in the final 112/15/14 shared-index target. The earlier underground-only R2 audit counted 29 because M000 was not yet present in MP03 ONLINE. The later shared-progress reconstruction added that missing online M000 and made the paired lists byte-identical; the subsequent resource-parity step repaired the still-stale 111-row online localization table. Never carry this older 29-instance patch count forward as evidence for the final two-mode lists.
