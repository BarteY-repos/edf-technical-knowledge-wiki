EDF5 tree TRB rules: weighted models, billboard thresholds and building LOD

EDF 5Game technical referencesVegetation and LOD
Technical reference · Source static evidence with unverified behavior labelled; no new in-game R132 test

A tree's TRB rule determines both its shape family and the values used when deciding when it becomes a billboard. Structure models use a different part/slot LOD table. Treating a single distance in a map resource as a universal EDF5 LOD radius obscures those distinctions.

TRB rule anatomy

In the ig_heigen507 corpus, 19 .trb SGOs were observed. Their rules and strings contain weighted model alternatives, optional stumps, trunk/branch identifiers and several numeric families. Selected children of rule 0 are:

Rule 0 child Observed contents Supported interpretation
0 Weighted model-name choices Chooses the tree model
1 Vec3, e.g. (0.5,9.0,0.5) or (1.0,33.5,1.0) Collision/trunk size inferred
2 Category such as 2 (tree) or 0 (bush) Collision role
3 Stump model or zero Post-fall representation candidate
4 [1000], [500], [400] or [80] Body property and display cutoff; not tree HP
5 Two values, such as [50,150] Billboard near/far switching values
6 樹木 (tree) Category/name marker

Other rules describe the far billboard card, leaf appearance and sway by named bones (miki trunk / eda branch). Model names such as sk_ptree013_40m_sugi encode characteristic heights; the engine picks from a finite set of models rather than continuously scaling each tree.

The [1000]-type number is copied into a Havok body property. Its exact gameplay reader was not identified; interpreting it as ordinary durability is contradicted by the grown-tree hit path, which has no damage threshold.

Billboard and building LOD

The tree pipeline uses distance fields from TRB rules and a billboard transition; the original notes include a per-map tally of rule values. Building LOD instead follows .mosb part names and per-part distance thresholds. Material shaders include fade/dither behavior, so a visual disappearance can reflect LOD choice, culling, or shader fade, not necessarily the removal of the physical body.

Boundaries: the distance fields were measured for inspected game assets and native routines, but drawing pass names and some per-parameter visual semantics were not resolved in the same study.
