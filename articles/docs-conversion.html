Overview

Porting resources between EDF4.1, EDF5 and EDF6 is not merely changing extensions. Reuse the source's semantics where they are understood, but produce the target's required container, type tags, paths and runtime ABI.

Version compatibility checklist

Check file header and alignment, target-side resource role, object/class behavior, map geometry, route data, list/thumbnail identity, localization and save-state coupling. Preserve the difference between exact-native, source-derived, static qualified and runtime observed.
