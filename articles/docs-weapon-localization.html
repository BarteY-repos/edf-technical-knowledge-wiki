Weapon Stat Text & Localization

EDF 6DocumentationFile Formats
Technical reference · Community-provided Japanese memo; source-specific and not independently rerun

At a glance

What this page covers: The visible stat line and the weapon's gameplay value come from different layers: weapon SGO parameters, WEAPONTABLE entries and localized weapon-text records.

How to use it: An upgradeable displayed value may use a numbered placeholder. Its position must agree with the parameter's star record; editing only the translated string can produce misleading text.

Evidence boundary: Use this page as a consistency checklist. The workbook-derived mapping should be checked for the exact weapon and localization before generalizing.

EDF6 weapon statistics have a display/localization layer separate from the underlying weapon SGO parameter. For star-upgradeable values, the source describes placeholders such as $0, accompanied by the same upgrade parameter record used by the weapon.

What must agree

  1. Weapon SGO: technical value, star-upgrade record and its position index.
  2. WEAPONTABLE: internal resource name/path, category, level, eligibility and star caps in matching position order.
  3. WEAPONTEXT language variant: human-facing title, description and stat label/formatter, sometimes with a $0 substitution backed by the seven-field star record.

Translation of the visible label does not change gameplay. Conversely, changing a gameplay statistic but leaving a hardcoded display string unchanged can mislead players.

Full source-table index without duplicating contributor translations

The original workbook's translation sheet contains 192 rows with numeric source IDs (翻訳用!A3:O194), covering weapon-description labels and formatting tokens across JP, EN, KR and Chinese columns; the full sheet is not an official global game-string registry. reference/R154_WEAPON_TEXT_TRANSLATION_ID_DIRECTORY.csv identifies each source row/ID, populated language columns and English short label. It is a navigation/index aid, not wholesale redistribution of the workbook's multilingual text. Placeholder and formatting strings such as $0 remain exact when modifying actual game resources. The 192 count describes numeric-ID sheet entries, not unique labels or guaranteed live WEAPONTEXT keys.
