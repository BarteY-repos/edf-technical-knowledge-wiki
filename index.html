Interpret the evidence correctly

Static file/binary findings, reconstructed or converted game content, and observations from a running game are separate kinds of evidence. A feature seen in a modified runtime is not proof of an equivalent stock-game behavior. A source-asset file in a port is not necessarily an original shipping EDF6 file. Examples of corrected misunderstandings include the debug-only FreeViewCamera, not a confirmed player photo mode, the EDF5-derived Desert grass sample, not a native EDF6 generic grass oracle, and collision geometry that does not prove AI NAV/LOS parity.
